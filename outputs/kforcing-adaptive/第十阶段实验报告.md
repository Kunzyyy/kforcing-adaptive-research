# 第十阶段：提前停止后的自适应质量与计算成本

日期：2026-09-20。预设的近似预算及两项性能联合门槛：**未通过**。

## 结论

本轮真正遇到提交的 EOS 就停止，没有继续执行 EOS 后的窗口。相对独立校准后冻结的主随机对照：

- 可见 token/s 比为 **0.9820 [0.9366, 1.0296]**；区间跨 1，没有可靠的吞吐量差异证据。
- GPT-2 Gen-PPL 比为 **1.0860 [0.9051, 1.3073]**；区间跨 1，没有可靠的 GPT-2 困惑度差异证据。困惑度不是人类语义质量。
- 每可见 token 的前向次数比为 **0.9725**，达到预先规定的 ±5% 近似预算范围。这是计算代理，不能称为 FLOPs 精确相等或每请求预算完全一致。

这轮排除了第九阶段“EOS 后计算混入完整长度预算”的主要干扰。是否支持算法收益仍以本轮完整生成、独立评分和实际耗时为准，不能用第八阶段局部教师匹配率替代。

**当前研究判断：冻结预测器仍没有可靠超过校准随机对照，不应继续把这条支线描述为已成功的自适应算法。** 点估计略慢且困惑度略高，但主要区间都跨 1；这既不是获益证据，也不能证明方法等价或普遍无效。

## 1. 完成的实验

- 新抽取 128 个源句：32 个校准、96 个测试，排除此前源行、原句哈希和六 token 前缀；无文档身份，无法排除全部近重复。
- 768 条校准生成，只用计算计数选择随机概率，不读取质量评分。
- **1,536 条测试方法/种子输出、4,608 次正式计时**。其中 192 条 replay 与 learned 的文本相同，只用于成本诊断，不能算作新增独立质量证据。
- 同一冻结 hidden82 预测器与阈值，基础权重不变。另有 192 次 learned 轨迹发现运行，仅用于重放诊断，耗时单独保存。
- fp32、tau=1、无频率惩罚、batch=1、六 token 前缀、最多 122 个新 token。

## 2. 如何处理结束符

先算四候选，若前两位已经含 EOS，直接停止，不做无用特征计算或尾部重算。否则预测器决定是否重算后两位；初始尾部里的 EOS 可能被替换，不能提前终止。保留的首个 EOS 确认后，整个请求退出。块内已经算过但未提交的位置照计成本。

32 条旧真实输出逐 token 重现阶段 9 的 EOS 截断结果；四个专门构造的结束符案例、八组重放与三组缓存/完整重算对照通过。

## 3. 预算如何校准

校准集对随机概率 0,0.1,...,1 逐项生成，以“总模型前向次数/总可见 token”接近 learned 为标准。learner 校准成本为 0.39460 次/token，选中 p=0.6 的随机成本为 0.40295 次/token。先保存校准文件及哈希，再生成测试。

主要比较始终使用 p=0.6；相邻概率只用于展示取舍。测试后未选择更有利的概率，也未重新调阈值。不同策略历史和停止位置不同，因此只保证校准集上的近似计算匹配，测试实际预算必须另外检查。

测试前向/token 比的探索性 95% 区间为 0.9725 [0.9365, 1.0090]。±5% 判据仅针对预先定义的点估计；区间并未全部落入该范围，不能把“点估计接近”表述为统计意义上的预算等价。

可见 token 计数含 EOS。请求耗时是本机解码调用，包含预填充、全部模型计算、EOS 与决策同步、缓存、特征、预测、重算、逐步日志；不含加载、随机数预生成、分词、写盘和离线评分，也不是网络服务端到端延迟。输出长度不同，不能只因更早结束就称为加速。

GPT-2 评分沿用既有续写单独解码、不加 BOS、首 token 不计损失的口径，按全语料 token 加权；短文本排除保留在原始统计。learner 排除 3 条，主随机排除 3 条。文本中的 WordPiece 标记或语病没有在测试后清洗以改善分数。没有人工盲评。

## 5. 统计与同输出成本诊断

两个主要终点各用 97.5% 双侧区间，Bonferroni 家族置信水平 95%；96 个源句聚类、同句两个种子一起重采样，共 4,000 次。每个输出的三次时间先取均值。主要质量/速度门槛要求 PPL 比上界<1、token/s 比下界>1，且预算代理比在[0.95,1.05]，本轮未通过。

learned 与已知决策序列的 replay **192/192 对输出及模型调用计数一致**。其平均请求延迟比为 **1.0520 [1.0337, 1.0732]**（探索性 95% 区间），点估计对应约 5.20% 的额外时间。这个差值覆盖当前特征、预测、hook 与决策路径，不只是一层线性模型计算。重放用到了预知的选择序列，不是可以免费部署的算法，也不是所有实现的理论成本下界。

## 6. 审计与研究判断

独立 CPU 审计已重算数据隔离、校准概率选择、随机决策、EOS 与重算计数、冻结模型哈希、4,608 个计时组合、评分聚合和主要 bootstrap 区间。scoring 使用校验过的本地 GPT-2-Large，交叉熵探针与内置 loss 一致。未独立复跑全量 GPU 运算。

本轮联合门槛未通过，不把不显著解释为等价。公开 k=4 检查点与论文质量基线的差距仍未解释；也未进行大模型、并发服务或人工质量验证。若要修改预测目标或降低特征成本，应另用训练/开发数据，再冻结新的独立测试，不能在这 96 个源句上调参后重复宣称泛化。

同输出重放给出的约 5% 成本表明当前决策路径存在工程负担，但还没有证据说明仅消除这个负担就会带来质量与速度的共同改善。更合理的后续方向是先在新的训练/开发数据上检验与完整文本质量更相关的收益目标；当前冻结模型保留为可复查的负结果基线，不继续只为局部教师匹配率扩大训练。
