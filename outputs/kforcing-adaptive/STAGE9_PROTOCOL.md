# 第九阶段：冻结预测器的完整生成检验

在抽取新样本及查看结果前固定，2026-09-20。

## 问题与不变项

阶段 7 的 hidden82_alpha001、82 维特征、投影及开发阈值全部冻结。测试阶段不训练、不调参。检验局部选择信号是否能迁移到模型自己生成的历史，并抵偿特征计算和重算成本。阶段 8 的确认不改写阶段 7 未通过的门槛。

## 数据

从本地已校验 LM1B held-out 文件抽取 64 个全新源句，前缀长度 6，原句至少 12 token。排除阶段 1–8 已有六 token 前缀、可获得的源行和原句哈希。本轮按上述身份去重；无文档身份，无法排除语义近重复。抽样种子 9092001；每句采样种子 907、911，实际噪声种子 90900000 + seed + index * 100003。

## 方法

五组：fixed2、fixed3、fixed4、learned、random_matched。每组 128 条，共 640 条独立生成。fp32、tau=1、无频率惩罚、batch=1；每条从 6 token 生成到 128，共 122 个新位置。模型权重不变，沿用已有 Windows eager 与 SDPA 适配。

learned 每四个输出位置先计算四个候选，按冻结阈值逐块决定是否保留前两位、以它们为真实历史重算后两位。最后不足四位时直接生成，不提取预测器特征。缓存只包含已提交的真实历史，丢弃的候选不得进入缓存。四候选的第一二位须在预检查中核对等于两候选分支。

random_matched 先获得同前缀同噪声的 learned 轨迹在 30 个完整窗口中的拆步总数，再用固定种子 9092003 + noise_seed 随机选择恰好这些数量的位置。它也先计算四候选，再按选择重算后两位。因此每对拥有相同模型前向次数和候选位置总数；上下文位置不同，实际算力和延迟不保证相等。它是使用事后预算的诊断对照，不是独立可部署策略。分配不读取文本评分，不按测试结果调参。比较中不向随机方法收取 learned 预算发现成本；明确报告此优势。

## 计时与质量

learned 的预算发现仅运行一次并保存，耗时单独标识，不计入主计时。正式每条生成重复三次，固定种子 9092005 打乱每个请求各方法的运行顺序；预热使用阶段 8 的旧前缀。三次输出及选择须一致。计时包含预填充、所有前向、特征提取、投影、线性预测、GPU/CPU 决策同步、缓存、尾部重算及逐步日志；不含权重加载、输入/噪声预生成、分词、离线评分和写盘。固定方法不计算选择器特征。

主吞吐量按固定的 122 个新位置计算，含 EOS 后位置，不能表述为用户可见文本速度或提前停止延迟。质量只取首个 EOS 及之前的续写。独立 GPT-2-Large fp32 评分沿用阶段 4 主口径：去特殊 token、重新分词、无 BOS、首 token 不计损失、按全语料 token 加权；短于两 token 的文本保留并报告排除。另报告教师条件 NLL、可见长度、EOS、重复三元组率。保存按前缀编号排序的前四个前缀所有方法/种子文本，不挑选好例子，不把人工查看当作盲评。

## 分析与结论规则

主比较 learned / random_matched 的 GPT-2 Gen-PPL 比与固定长度吞吐量比。按源句聚类（两种子一起）bootstrap 4000 次，种子 9092004；三次耗时先按单条输出取均值，不能视为三个独立质量样本。两个主终点各用 97.5% 双侧区间（Bonferroni family 95%）。只有 PPL 比区间上界 < 1 且吞吐量比区间下界 > 1，才称主比较同时改善。若出现取舍，如实报告，不追加事后非劣界限。不满足不等于证明无效。与 fixed2/3/4 的比较为探索性 95% 区间，不保证新方法优于所有固定步长。单 GPU 顺序实验不能覆盖跨机器计时波动。

验证官方检查点哈希、冻结选择器/投影/特征代码哈希；旧窗口重放；fixed 与既有解码器对齐；始终拆步与 fixed2 对齐；learned 缓存与重算对齐；CPU 原预测函数与在线分数一致；全部计数/配对/数据隔离审计。预检查失败先修实现并记录，不读取测试评分选实现。
