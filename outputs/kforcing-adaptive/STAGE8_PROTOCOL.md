# 第八阶段：冻结预测器的新样本确认与上下文长度转移

在新样本选择和结果产生前冻结。模型固定为第七阶段 `hidden82_alpha001`，其标准化参数、系数、64 维投影及 dev 阈值全部保持不变。不重新拟合，不挑新模型，不用本轮数据调阈值。

## 样本

- 已核验 LM1B held-out parquet；固定打乱种子 8081701。
- 排除阶段 4–7 的原始源行、句子哈希和六 token 前缀，以及阶段 1–3 的既有前缀。新样本按原句哈希和六 token 前缀去重。
- short：256 个新句子，token 长度至少 12，使用长度 6 的上下文。
- long：另外 128 个新句子，token 长度至少 36，同一句分别取长度 16 和 32 的真实上下文，均含首个 CLS，且上下文内不得有 EOS。
- 每个上下文用 8 个固定噪声种子：829/839/853/857/859/863/877/881；共 4,096 个四 token 窗口。16/32 上下文共享其对应噪声，按源句聚类处理相关性。
- 来源句子与既往不重合；缺少原始文档身份，无法保证文档级或语义近重复隔离。长上下文来自真实文本，不代表模型在线生成历史。

## 计算与比较

延续 fp32、tau=1、频率惩罚 0；同一噪声下计算 fixed4、split22 及逐 token AR 逆 CDF 参考。只用 fixed4 第一次前向时可取得的 82 维特征做预测。

每个长度队列独立排序，恰好选 50% 窗口拆步。比较冻结预测器、预定尾部置信度、固定随机种子 8081703 的等预算随机、知道标签的 Oracle，以及全固定/全拆步。另单独报告原 dev 阈值的选择率和与相同选择概率随机期望的差异；不把预算漂移当成增益。

两个主要确认终点：

1. short 队列中，冻结预测器相对 50% 随机期望的教师耦合 token 匹配增益。
2. long 队列中，将 16/32 两种上下文合并后，同一指标的增益。

按源句聚类、保留全部噪声和该句全部上下文，4,000 次 bootstrap。每个主要终点用 97.5% 双侧区间（两个终点 Bonferroni 校正对应家族 95% 覆盖）；其余报告 95% 探索性区间。两项主要区间下界均大于 0 才记为“本次局部确认通过”；若未通过，停止这一个预测器的在线推进，不改变门槛或追加模型直到显著。通过也只允许考虑后续在线实验，不代表已有质量或速度提升。

## 预先指定的旁证

同一教师对两条 PFLM 分支各自的真实历史计算四个候选 token 的条件 NLL，记录 `NLL(fixed4)-NLL(split22)`。检查按耦合匹配标签训练的选择器在教师似然指标上的方向；此指标不是外部文本质量保证，也不用于选择模型或取代主要终点。

## 完整性

保存冻结模型/投影副本及 SHA-256，输出每条分支、噪声、特征、预测和 NLL。特征提取只在第一次 fixed4 前向挂钩。验证缓存长度，核对原始与复制预测器哈希，审计句子/前缀隔离、选取预算、预测与汇总。历史阶段的协议、结果和 zip 不覆盖。
