# 第六阶段：拆步有局部收益，现有信号仍然选不准

## 结论

**这一轮没有找到能解释论文质量差距的公开版本变化，但把自适应问题缩小到了“怎样选中真正受益的窗口”。**

在 1,024 个固定上下文、固定噪声的局部窗口上，将一次生成 4 个 token 改为两次各生成 2 个，与 AR 参考采样的 token 一致率从 **31.76% 提升到 33.03%**。改善为 **1.27 个百分点，95% 区间 [0.32, 2.20]**。

然而，只给一半窗口额外计算机会时，预定的“尾部候选置信度低就拆步”规则仍未胜过同预算随机选择。**继续微调这一项置信度阈值，不是当前有证据支持的主路线。**

这里的一致度是特定噪声耦合下的诊断指标；它不是文本质量、分布距离或真实在线加速的证据。基线复现根因仍未定位，自适应方案仍未成立。

## 2. 新实验测量什么

沿用第四阶段 128 个 LM1B 六 token 前缀作为诊断集，每个前缀使用预先确定的 8 个噪声种子，共 1,024 个窗口。全部使用 fp32、tau=1、无频率惩罚。

对同一组 4 个均匀噪声，计算三条分支：

1. **AR 参考**：每生成一个 token，都把它加入上下文，按教师概率的累积分布与对应噪声选择下一个 token。
2. **固定 4**：PFLM 一次生成四个候选。
3. **2+2**：PFLM 先生成两个，将实际候选加入上下文，再用后两个噪声生成两个。

关键区别是 2+2 的后半段可以看到前两个已选 token。两条 PFLM 分支的前两个 token 在全部窗口上完全一致，缓存长度检查通过。首步 AR 参考与源码的对应逆 CDF 构造在 16 条样本上一致；另有简单概率分布检查。

**这个 AR 参考不是 k=4 检查点的已知真实训练标签。** 逐级蒸馏可能经由中间 PFLM 教师，不同的均匀噪声映射也可以具有相同分布。因此，本实验只能回答该明确参考下的局部拆步问题，不能把不一致比例解释成模型“错误率”。

协议在运行前固定：[STAGE6_PROTOCOL.md](STAGE6_PROTOCOL.md)。

## 3. 拆步的效果在哪些位置

| 候选位置 | 固定 4 与 AR 参考一致 | 2+2 与 AR 参考一致 |
|---|---:|---:|
| 第 1 个 | 59.08% | 59.08% |
| 第 2 个 | 32.71% | 32.71% |
| 第 3 个 | 19.73% | 22.66% |
| 第 4 个 | 15.53% | 17.68% |
| 全部 token 汇总 | **31.76%** | **33.03%** |
| 四个 token 全部匹配的窗口 | 5.18% | 9.47% |

收益集中在后两个位置，符合拆步让后半段读取真实候选的机制。在 1,024 个窗口中，按匹配 token 数计算：

- **117 个**拆步后更接近参考；
- **74 个**拆步后更远离参考；
- **833 个**匹配数量不变。

“数量不变”不等于生成文本相同。更接近参考也不等于语义质量一定更高。全部固定四位置都纳入主汇总；其中 65 个窗口至少有一条分支含 EOS。三个分支均无 EOS 的 959 个窗口中，汇总一致率为固定 4 的 32.19%、2+2 的 33.55%，方向一致。

## 4. 相同额外计算预算下，能否选对窗口

信号、随机和 Oracle 都恰好选择 512 个窗口拆步。信号只用固定 4 候选后两位的平均 top1-top2 间隔，从低到高排序。随机使用预定种子；Oracle 则读取 AR 参考答案，优先选择真实匹配收益最大的窗口。

| 选择方式 | 拆步窗口数 | 汇总 token 一致率 | 完整窗口匹配率 |
|---|---:|---:|---:|
| 全部固定 4 | 0 | 31.76% | 5.18% |
| 置信度信号 | 512 | 32.42% | 6.93% |
| 随机选择 | 512 | 32.45% | 7.52% |
| Oracle：知道参考答案 | 512 | **34.99%** | 9.96% |
| 全部 2+2 | 1,024 | 33.03% | 9.47% |

按前缀聚类、保留每个前缀的八个种子，2,000 次 bootstrap：

- 信号减随机：**−0.02 个百分点 [−0.54, +0.49]**，无明确优势。
- 信号减等预算随机的解析期望：**+0.02 个百分点 [−0.39, +0.43]**，结论相同。
- Oracle 减随机：**+2.54 个百分点 [+2.03, +3.10]**。

Oracle 显示这批窗口上的收益并非完全均匀，存在可被“知道答案的选择器”利用的空间；它不能证明廉价信号可以预测这些收益。按信号在整批诊断样本中排序，也不是独立数据上的部署评估。bootstrap 保留原有选择，不重新拟合排序。

这里没有测量速度。固定 4 一次前向、2+2 两次前向；局部同预算只比较这些理想分支的次数。若在线先算四个候选再因信号决定重算，费用还包括被丢弃的候选、特征提取和调度，不能据上表声称加速。

## 5. 对后续工作的判断

我建议将“单个置信度阈值”的实验分支暂时收束。前几轮的外部评分，以及这轮更直接的局部诊断，都没有支持它优于随机策略。

可继续检验的研究问题是：**能否用便宜且不调用教师的特征，预测拆步的实际收益？** 本轮已经提供逐窗口的同噪声分支和收益标签，可作为诊断材料。若尝试新的预测器，应另行冻结训练、开发、测试数据；先要求在同预算离线选择中胜过随机，再支付真实在线成本，并用外部质量评价复核。教师耦合一致度不能成为唯一训练或评判依据。

基线复现差距继续单独保留为未解问题。在没有完整作者配置或原始环境对照前，不再反复换指标挑选更好看的结果。公开版本核查结果已补充进[待作者核对的技术说明](复现差异说明_待作者核对.md)。
