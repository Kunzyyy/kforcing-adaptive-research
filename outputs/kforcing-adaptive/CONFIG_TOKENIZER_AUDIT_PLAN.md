# 历史配置与分词器兼容性核查

2026-09-21。回顾性工程诊断，不是新方法实验或预注册确认。

初查已经看到：历史词表与当前词表相同，历史慢速BERT分词器按现有版本恢复后，旧基线2048条续写decode文本均一致。以下固定剩余核查范围，不以结果接近论文数值为筛选标准。

1. 从两份历史data.pkl语法记录读取词表、特殊token、basic/wordpiece参数；不执行旧pickle对象、不运行OmegaConf插值或历史训练路径。
2. 以本地transformers 4.55.0分别构造慢速BertTokenizer与当前BertTokenizerFast。完整核对30522项词表和特殊token；用第16阶段1024源句比较编码（含CLS/SEP及128长度截断）和旧冻结前缀；核对2048条生成文本、EOS和decode。原训练时的tokenizer库版本未知，本检查不等价于旧环境重现。
3. 使用当前公开普通权重和相同模型源码，分别按当前loader配置和历史model字段实例化。strict加载、eval模式，不启用训练恢复。
4. 在第16阶段固定输入工具的160个PFLM输入（400候选位置）上比较完整logits与argmax；其中k=4的40个上下文额外比较AR最后位置log-probs。容差maxabs<=1e-6且argmax相同。已有EOS之后上下文仅用于数值诊断。
5. 缓存路径：用相同8条固定上下文的6/10/14/30/70位置，固定noise按原case选取，依次扩展缓存，比较两模型缓存及输出；AR首批完整128 token生成对照，额外固定32个旧源句的AR/K4全长生成对照。不同配置只比较各自相同输入/随机种子，不重新计算质量或寻找新指标。
6. 输出配置差异表、逐条记录、哈希、版本信息和不一致样例。若全部一致，保留当前loader和旧结论；如失败，先定位具体差异再决定是否需要质量重评。

本轮不切换EMA、归一化、评分口径、模型参数，不增加新源句，不重训自适应选择器。既有阴性研究结果不受这项兼容性检查改写。
