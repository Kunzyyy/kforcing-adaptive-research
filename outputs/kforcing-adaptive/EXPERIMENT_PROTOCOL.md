# 第一轮实验协议

## 假设与边界

假设：上一轮平均 logit 间隔包含下一轮步长选择有用的信息。该假设可能不成立。

第一轮不训练 PFLM、不使用教师模型在线验收、不承诺保持教师采样分布。自适应启发式本身不宣称新颖。

## 固定条件

- PFLM：官方 `pflm_lm1b_k4.ckpt`，严格 state_dict 加载。
- 教师评分：官方 `ar_best_lm1b.ckpt`，离线 fp32 全上下文计算。
- 数据：WikiText-2 raw；validation 8 个前缀用于校准，test 20 个不同前缀用于测试。
- 每个前缀：`[CLS]` + 5 个 BERT wordpiece；各策略使用同一前缀。
- 生成上限：64 个新 token，含 EOS；遇到 `[SEP]` 停止。
- 精度：PFLM 使用 bf16 autocast；原作者强制 fp32 的子运算予以保留。
- batch=1；种子 17、29；随机噪声按输出位置索引。
- 所有策略频率惩罚均为 0.5，与原作者默认值一致。
- 固定 2、固定 3、固定 4、自适应 2/4、随机 2/4。
- 自适应首轮为 4，此后根据上一轮 raw logit 的平均 top1-top2 差值选择。
- 阈值为 validation 上固定 4 的差值中位数；随机短步概率为 validation 上自适应策略实际短步比例。
- 测试时不会根据结果选择新阈值。

## 计时与评价

耗时包括从 prefill 到停止的模型推理、策略、缓存管理、EOS 检查和各策略相同的诊断信息采集。固定及自适应均计算诊断量，因此这是带共同诊断开销的原型比较，部署性能还需去掉无关诊断重新测试。冷启动、加载、分词、随机噪声预生成和离线教师评分不计入。

先按 EOS 截断，再统计真实输出 token 数。各策略可能生成不同长度，必须同时报告平均长度与 EOS 比例。每个 prompt-seed 内随机打乱策略次序；统计置信区间以 prompt 为聚类单位，保留同 prompt 的两个 seed。

教师 NLL 仅描述教师给生成样本的似然。它不等于人类评价，更低的 NLL 可能意味着较低多样性。重复率是第二个诊断指标，仍不能替代独立质量评分。

## 继续/停止标准

本轮仅判断是否出现值得进一步验证的信号，不以少量代理指标宣布等质量加速。

若自适应不能超过随机选择或固定方案，应先分析信号是否真的能预测使用小步长的边际收益；不能在同一个测试集上反复调阈值直到获胜。

若出现有利信号，下一轮需：同分布 LM1B 数据、更多样本和 seed、独立质量评价、长度受控计时、无多余诊断的实现、相邻自适应方法比较，再讨论多请求调度。

## 工程记录

- 6 项小模型语义测试通过；测试输出头随机化，避免零初始化带来的虚假一致。
- 实际检查点 fp32 预检查：变化窗口的缓存/重算差异为 0；短窗口/完整窗口前缀最大差异约 2.48e-5。
- 上述检查验证便携代码内部语义，不等同于在作者 Linux/FlashAttention 环境逐位对照。
- 官方 CLI 会将 `max_k` 设为 `args.K`，因此此前关于固定基线总是多算的担忧不成立。
