# 第五阶段：固定 k=4 复现偏差的受控排查

在查看本轮新结果前冻结。目标是定位第四阶段基线差距，不选择新的自适应控制器。

1. 沿用第四阶段 128 个 LM1B 前缀及种子 617/619，作为诊断集。公开 k=4 采样器、batch=4、固定 122 新位置、tau=1、频率惩罚 0。保留 fp32 控制，另加外层 bf16/fp16 autocast；不直接转换全部权重，因为源码部分投影要求 fp32。
2. 每批预生成原采样器顺序的 31 个 (4,4,1) CUDA 均匀噪声块，三个精度路径重放完全相同张量。fp32 控制必须逐 token 重现第四阶段全部 256 条 k=4 输出。新生成总记录 768 条，其中 256 条为重现控制。
3. 对前 32 个前缀在固定上下文长度 6/10/14/30/70 上，比较同上下文、同噪声的 fp32/bf16/fp16 logits 与 argmax。用 fp32 路径累积 KV，另与完整上下文重算比较。小规模核对训练 staircase 与推理 causal 路径的末窗口结果。记录差异，不把自回归发散的后续 token 不同全部归因于局部数值误差。
4. 用既有本地 GPT-2-Large fp32 评分器统一评价三种 k=4 精度与第四阶段 AR，共 1,024 条文本。主要指标仍是第四阶段 completion-only/no-BOS Gen-PPL；同时单独列出“含前缀的完整文本”与“续写前加 GPT-2 EOS 作为 BOS”的评分敏感性结果。不把更接近论文的替代值事后认定为论文口径。
5. 同一前缀两个种子成组进行 2,000 次配对 bootstrap，报告精度变化的 PPL 比及区间。旧样本只作诊断，不用于新方法的最终测试。保持阶段 1–4 记录和 zip 不变。
