# 历史 EMA 检查点定向诊断

日期：2026-09-21。此协议在任何历史 EMA 生成或质量评分前写入。

## 新证据与假设

Hugging Face 历史 revision `6b357e2893399a3c0219df6ef62af8fc6af747a4` 的完整 LM1B 检查点保留了普通 state_dict、EMA、训练配置。元数据以 HTTP 精确区间读取、ZIP CRC 校验和不执行对象的 pickle 语法解释获得。

当前 PFLM 的109个状态张量、AR的101个状态张量在形状、长度、CRC32上与历史普通 state_dict 对应；按顺序对应的EMA分别108/100个参数均不同。历史配置中两者 eval.disable_ema=false。**CRC一致不是全文件密码学验证；配置存在不证明论文评测一定执行了该配置。**

检验假设：普通参数与EMA选择可以解释部分当前基线质量差异。EMA没有参数名，以历史 state_dict 的参数顺序（去掉 rotary buffer）对应 EMA列表，并要求全部形状/步幅/类型和发布模型 named_parameters 顺序一致。即使这些检查通过，仍不能代替原训练代码对列表语义顺序的确认。

## 固定诊断

- 只使用第16阶段已经用过的1024源句中的前128条；这是回顾性基线诊断，不是自适应新测试。
- 两个模型分别比较当前普通参数与历史EMA；模型源码、LayerNorm、tokenizer、前缀、批次、种子和评分口径保持第16阶段设置。
- batch=4，seed=16120000+batch_index*101，tau=1，PFLM K=4、频率惩罚0，122新位置；质量在第一个生成EOS截断。AR沿用公开CLI内部fp16，PFLM fp32且无外层autocast。
- 普通参数生成复用旧记录，并重放首批验证；EMA生成各128条。所有旧/新共512条重新评分，核对旧256条总NLL/计数。
- GPT-2-Large fp32，续写去BERT特殊符号、重新分词、不加BOS、首个GPT token不计分、语料token加权Gen-PPL。不给EMA单独调精度、温度或惩罚。
- 每模型报告EMA与普通参数的平均token NLL差和PPL比值；4000次配对源句bootstrap，seed=21212026，95%描述区间。旧样本被反复观察，不作确认性显著性结论。
- 不把接近论文数字当作通过标准；不根据本轮结果重写旧自适应收益、宣布错误根因或论文复现成功。
