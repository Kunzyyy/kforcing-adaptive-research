# 第七阶段：冻结模型内部表示能否预测拆步收益

在新数据选择、采集及拟合前固定。任务是筛查廉价收益预测的可行性，不继续调单一置信度阈值，不训练基础语言模型。

## 数据隔离

从已核验的 LM1B held-out parquet 中，按固定种子 7071701 打乱原始行，排除阶段 4–6 的源行、文本哈希和六 token 前缀，以及阶段 1–3 的既有前缀。保留 token 长度至少 12 的句子。按六 token 前缀、原句哈希去重，选 448 个前缀，先 256 train、再 64 dev、最后 128 test。不同 split 的前缀和原句均不得重合；shuffled LM1B 缺少原文档身份，不能保证文档级隔离。

每个前缀预定 8 个噪声种子：761/769/773/787/797/809/811/821。只使用六 token 上下文，fp32、tau=1、无惩罚。对应 2,048/512/1,024 个窗口。test 标签仅在开发集选择完成并保存模型后采集。

## 标签与特征

沿用第六阶段：同噪声下，标签为 split(2+2) 比 fixed4 多匹配的 AR 逐 token 逆 CDF 参考 token 数。保存三条分支和噪声，不将此标签当作文本质量或真实训练标签。

预定两种特征集合：

- confidence14：四位置的 top1-top2 间隔、熵、top1 概率及尾部减头部平均间隔/熵。
- hidden82：confidence14，加后两个候选在输出线性层之前的归一化隐藏向量均值，经固定随机投影降为 64 维，再加四个已知均匀噪声数。投影种子 7071702，Gaussian / sqrt(hidden_dim)。只能读取候选 logits 产生前后已经可用的信息；不得读取 AR 或第二次生成的隐状态作为特征。

两组均仅在 train 上标准化、拟合带截距岭回归；alpha 仅试 1/10/100。按 dev 上固定 50% 选择预算相对随机期望的 token 匹配收益选择候选；相同收益时按候选名称顺序决定。不扩充特征或 alpha 列表追逐正结果。

## 锁定与一次测试

选定后保存均值、标准差、系数、特征类型、alpha、开发选择中位阈值和训练/开发数据哈希，再采集 test。即使开发收益不显著，也只对该固定候选进行一次测试，完整报告，之后不得按测试重选。

主要 test 对照：对锁定分数排序，恰好选择一半窗口，与等预算随机期望以及固定种子 7071703 的随机选择比较。排序预算用于隔离预测能力，不代表可部署阈值。另报告锁定 dev 中位阈值在 test 的选择率及相同总体概率随机期望，暴露预算漂移。报告置信度基线和知道答案的 Oracle；不得用它们在 test 上重选模型。

按前缀聚类保留八个噪声种子，2,000 次 bootstrap。开发门槛和独立 test 相对随机期望的收益区间下界均大于 0，才具备进入在线实验的资格；否则本轮停止于离线结果。即使通过，也尚需完整生成、外部质量评分和真实特征/决策/丢弃计算成本测试，不能提前宣称方法有效或加速。
