# 评分目标审计：等长比较与评分器一致性

2026-09-21。对已公开结果的阶段15数据做回顾性诊断，不是独立测试，不增加一个算法成功阶段。

## 要回答的问题

完整续写 GPT-2 平均 NLL 改善，是否在两分支只比较相同数量的评分位置后仍存在？重算是否同时改变长度、停止位置、计算量？原 AR 教师的条件平均 NLL 是否同向？

本轮不拟合模型、不选阈值、不改变阶段15的失败结论。基线与论文的差距仍需作者权重/配置核对。

## 固定材料和方法

- 输入是阶段15全部 5,464 对已生成分支、已保存标签和冻结预测。按照原规则保留八次均可评分的 682 状态、381 源句；不删除相同文本或零收益。8 个无效分支对保持记录。
- 对全部 8,810 个唯一续写重新运行本地 GPT-2-Large fp32。沿用 completion-only、无 BOS、去 BERT 特殊 token 的原口径，保存每个被评分 GPT-2 token 的 NLL。总和、计数与原始评分逐条核对（浮点求和误差允许绝对 1e-4）。评分前验证模型文件 SHA。
- 对每对分支令 m=min(keep4 评分 token 数, split22 评分 token 数)。共同长度收益为两分支各自前 m 个被评分位置的平均 NLL 之差。这里“共同”指数量相同，不要求生成 token 相同；首个 GPT-2 token 仍不计分。利用因果模型，截取损失不应改变较早位置的预测；另用截短重算验证。
- 逐对定义原收益 D、共同长度收益 C、剩余项 D-C。此为评分区间变化的代数分解，不能把 D-C 解释为长度的因果效应。共同长度依赖两个生成结果，也不能用作在线决策特征。
- 按状态平均八次，报告 D、C、D-C、AR 条件平均 NLL 收益、长度变化、调用次数变化。正 NLL 收益表示 split22 得分较好；长度和调用量使用 split22-keep4，正数表示更长/更多。
- 同时报告各分支 corpus token-weighted PPL，区分它与训练用的逐序列平均 NLL。AR 指标使用原标签、包含生成 EOS；GPT-2 指标不含 EOS。因此数值尺度不直接比较，也不是独立的人类质量评价。
- 使用原先冻结的线性/RBF/启发式半预算选择，检查 D 与 C 下的对随机和启发式差值；只作描述，任何新正数都不能挽救原确认失败。
- 以源句聚类重采样 4,000 次，seed=21092026，95% percentile 描述区间，保留同句全部偏移和八次重复。每次重新求均值/总 NLL 比值，排名保持冻结；不把 5,456 对当独立样本。多项探索不构成新的显著性确认。
- 按 split22 更短/等长/更长分层只描述样本，分层由生成结果决定，不能作因果结论。检查两半标签相关性以及两评分器/长度变化的相关性。

## 复核与交付

先冻结此计划、执行代码和历史输入哈希，再重评分。核对旧总分、内置 loss、截短不影响早期损失、所有重复映射、有效状态数、原 D 均值、统计汇总以及历史输入未被改变。结果写独立目录 `results/reward-audit`，保存已有归档。

报告必须区分：重算的代理评分信号、预测器能否提前找到信号、完整在线质量/速度是否改善。后两者没有因本审计自动成立。
