# 第十阶段：EOS 提前停止与校准计算预算

2026-09-20，在抽样、校准和查看测试结果前固定。

## 不变项及目标

保持阶段 7 的 hidden82_alpha001、特征投影、标准化、系数及阈值完全不变。基础模型 fp32、tau=1、无频率惩罚，batch=1，前缀 6 token，最多 122 个新 token。遇到实际提交的首个 EOS 立即停止，不继续生成 EOS 后的窗口；已经发生的块内多余计算照计。

四候选的前两位若已有 EOS，可直接停止，不计算预测器，也不重算尾部；否则对四候选执行冻结决策。初始尾部候选含 EOS 时，必须先决定是否重算，不能因一个将被丢弃的 EOS 提前终止。固定 k=2/3/4 也执行相同意义的 EOS 停止。缓存只含真实历史。

## 数据与校准

抽取 128 个全新 LM1B 源句，排除阶段 1–9 的既有六 token 前缀及可获得的源行/原句哈希；前 32 个用于预算校准，后 96 个用于测试。原句至少 12 token，按行、哈希、前缀去重，缺少文档身份。抽样种子 10102001；每句种子 1009/1013，实际噪声种子 101000000 + seed + index*100003。

校准集先运行 learned 及随机拆步概率 0.0,0.1,...,1.0 共 11 个候选。校准不进行教师或 GPT-2 质量评分。每候选以总前向次数/总可见新 token 为计算代理，选择与 learned 的对数成本比绝对值最小者，平手选较小概率。锁定随机概率及校准文件哈希后才开始测试。另冻结相邻概率 p_low=max(0,p-0.1)、p_high=min(1,p+0.1)，边界可重复，重复时仍透明保留。不能根据测试质量或预算重新选择 p。

不同策略生成历史与停止位置不同，这只能匹配校准集上的成本代理，不能保证测试逐请求预算相等，也不是精确 FLOPs 匹配。报告测试前向/token、候选/token、拆步比例及实际延迟；若主要测试前向/token 比不在 [0.95,1.05]，必须标明预算没有达到预设的近似可比范围。这个范围是描述性预算判据，不是质量非劣检验。

## 正式测试与诊断

八组：fixed2/fixed3/fixed4/learned/random_low/random_cal/random_high/learned_replay。96 源句×2 种子×8=1536 条输出，三次随机次序计时=4608 次。方法顺序种子 10102005。

learned_replay 直接重放同请求的 learned 决策序列，省去特征与预测；它必须逐 token 等于 learned，仅用于估计决策路径开销，不是可部署算法。每请求先运行一次 learned 发现轨迹，发现耗时单独保存，不用于正式统计。随机方法只用校准概率和位置索引的独立均匀数（种子 noise_seed+10102003），不读取 learned 测试输出、预算或质量。

计时包含预填充、EOS 检查与必要的 GPU/CPU 同步、全部模型调用、缓存、特征、投影、预测、重算和逐步日志；排除权重加载、预生成随机数、分词、写盘及离线评价。此处请求延迟指本地解码调用，非网络服务端到端延迟。记录平均请求延迟、p50/p95 和实际可见新 token/s（含 EOS token），不以只缩短输出宣称加速。

## 评分、统计与结论

延用阶段 9 独立 GPT-2-Large 主评分口径和教师 NLL 旁证；空文本/单 token 的排除数量保持可见。前四个测试前缀的全部方法与种子输出按编号展示，不能按质量挑选，不作人工盲评声明。

两个主要终点为 learned/random_cal 的 GPT-2 PPL 比与可见 token/s 比。按 96 个源句聚类、两个种子共同重采样，4000 次 bootstrap，种子 10102004；三次计时先对每条输出取平均。两个终点各用 97.5% 双侧区间，Bonferroni family 95%。只有 PPL 比上界<1、吞吐量比下界>1，且测试前向/token 比在[0.95,1.05]，才称在预设近似预算下两项同时改善；否则据实报告差异及预算情况，不能追加事后非劣门槛。

固定步长与相邻概率比较、请求延迟比、teacher NLL、replay 开销均为探索性 95% 区间。不能用较高/较低随机概率中最好看的一项替换主比较。单 GPU 计时不涵盖跨运行环境波动，GPT-2 PPL 不是人类质量，公开基线与论文的差距仍未解决。

## 验证

在旧数据上验证阶段 9 可见 token 重放、固定解码一致性、缓存/重算一致性；专门构造头部 EOS 与被重算移除的尾部 EOS 案例；确认同输出 learned_replay 一致。新数据、模型、投影、校准文件均锁定哈希；独立审计验证无 EOS 后窗口、真实计算计数、随机选择、全部重复输出和统计区间。
