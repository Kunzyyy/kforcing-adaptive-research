# 第十二阶段：收益标签有多大噪声？

2026-09-20 · K-Forcing 自适应解码 · 本地重复续写诊断

## 结论

**单次完整续写收益的随机波动较大；多次平均后，状态之间仍有可重复的收益差异。但现有两个预测器尚未捕捉到这些差异。**

96 个新源句、340 个有效决策状态，每状态固定当前历史、候选和特征，只改变未来续写噪声，重复八次。73% 的状态出现过收益正负翻转；前四次与后四次平均收益的相关系数为 **0.703，95% 区间 [0.604, 0.780]**。按方差分解估计，标签可靠性从单次的 **0.361** 提高到八次平均的 **0.819**。这里的可靠性表示状态间信号所占的方差比例，**不是模型预测准确率**。

这支持下一步用多次平均标签做受控训练实验，但不能证明噪声是前面失败的唯一原因，也没有证明自适应解码的质量或速度提升。本轮不重新训练模型，不修改阶段 7、11 的预测器和既往结论。

## 2. 如何确保只改变未来

在 fixed4 历史的生成偏移 0 或 8 处，先得到当前四个候选。keep4 保留四个候选；split22 保留前两个，重算后两个。之后两边均采用 fixed4，且在同一次重复中共用按绝对输出位置索引的未来噪声。

八次重复固定从开始到当前四候选末尾的全部噪声，只替换当前块之后的噪声。程序逐状态断言八次的历史、当前噪声、两种候选和 82 维特征完全相同，保存每次混合噪声的种子及 SHA256。审计独立重建全部 2,720 份噪声并核对哈希。

预检使用旧数据验证了 12 对原始分支精确复现，以及 24 对改动未来噪声后的分支与独立早停解码器精确对齐。35 个重算前后候选完全相同的状态，在全部重复中两分支输出一致，没有发现由不同缓存路径造成的输出分叉。

采集前冻结了 [实验协议](STAGE12_PROTOCOL.md)、采集和分析代码、特征投影、两个既有预测器的哈希。阶段 11 的评分代码直接复用，未修改。

## 3. 收益与重复性

收益定义为 `GPT-2 平均 NLL(keep4) − GPT-2 平均 NLL(split22)`，正值表示重算后的文本在该评分器上更好。每个分支先对完整可见续写求每 token 平均 NLL，再按状态等权统计；它不同于语料按 token 加权的 Gen-PPL。

| 稳定性指标 | 估计 | 95% 描述区间 |
|---|---:|---:|
| 八次中同时出现正、负收益的状态比例 | 72.94%（248/340） | 68.04%–77.68% |
| 前四次 / 后四次平均收益相关 | 0.703 | 0.604–0.780 |
| 两半平均收益严格同号 | 59.71%（203/340） | 53.75%–65.51% |
| 两半平均收益异号 | 29.12%（99/340） | 23.76%–34.57% |
| 两半至少一半为零 | 11.18%（38/340） | 7.85%–14.79% |
| 单次标签可靠性估计 | 0.361 | 0.278–0.438 |
| 八次平均标签可靠性估计 | 0.819 | 0.755–0.862 |

两半相关较高并不表示每个状态的收益符号都已确定：仍有约 29% 的状态，两组四次平均一正一负。不能把八次平均当成完全无噪声的真实期望。

方差分解：状态内方差均值为 **0.8311**；八次均值的状态间观测方差为 **0.5725**；减去 `0.8311/8` 后，状态间方差估计为 **0.4686**。由此估计单次标签约 64% 的总方差来自未来续写波动。该估计依赖本轮状态分布和固定的八次采样，不是对所有任务的普遍比例，也不保证某个模型能学到剩余信号。

分层检查得到一致现象：305 个候选发生变化的状态中，81.31% 出现过正负翻转，两半平均相关为 **0.702 [0.599, 0.779]**。35 个候选完全相同的状态收益全零；12 个两分支在当前块均已 EOS 的状态也全零。这两个子集有重叠。零方差子集的相关和可靠性无法定义，结果文件保存为 `null`，没有强行记为 0 或 1。

## 4. 用一组续写找到的机会，能否在另一组重复？

每次都选恰好一半状态。用前四次平均收益排序选位置，在后四次上评估相对同数量随机选择的收益；反向再做一次。

| 使用未来结果的离线比较 | 每状态平均 NLL 收益 | 95% 描述区间 |
|---|---:|---:|
| 前四次选位置，后四次评价 | +0.1770 | +0.1295 至 +0.2278 |
| 后四次选位置，前四次评价 | +0.1620 | +0.1151 至 +0.2119 |
| 两方向平均 | **+0.1695** | **+0.1241 至 +0.2185** |
| 同一半同时选位置和评价 | +0.2855 | +0.2540 至 +0.3208 |

交叉评价明显低于用同一批结果选位置并评价，说明后者会夸大可重复收益。交叉评价仍有正的描述性区间，支持继续研究状态之间的平均收益差异。

**这个选择器读取了未来续写的评分，不能在线部署。** 它提供的是目标重复性的诊断证据，不是已实现的自适应策略。相同干预次数也不等于完整生成具有相同计算量：EOS 和文本长度可能不同。

## 5. 两个冻结预测器怎样？

预测器仅读取当前决策前特征，按原有参数打分，选择一半状态；下面的评价目标为本轮八次平均收益。

| 冻结预测器 | 与平均收益的相关 | 相对同数量随机选择的收益 | 95% 收益区间 |
|---|---:|---:|---:|
| 阶段 7：hidden82 | +0.0038 | −0.0146 | −0.0564 至 +0.0264 |
| 阶段 11：confidence14 | −0.0016 | −0.0201 | −0.0594 至 +0.0160 |

两者的排序收益都没有可靠优势，相关也接近零。本轮没有依据这些结果重新选模型、反转符号或调整阈值。虽然平均标签的重复性有所改善，**已有预测器并未因此自动变好**。

我们还不能区分：单次标签训练造成了多大损失，现有特征是否不足，模型形式是否过于简单，或这些因素是否共同存在。下一步需要受控对照。

## 6. 接下来做什么

下一步优先安排一个能够区分原因的实验：**保持特征和模型候选一致，比较单次标签训练与八次平均标签训练**，开发集选择后锁定，再在尚未使用的新测试源句上评价。这样可以直接检查“改进训练标签”是否真的改善泛化，而非同时更换目标、特征和模型后无法解释原因。

本轮 96 个源句已经用于诊断，不再充当下一阶段的独立最终测试集。离线收益得到独立确认后，才值得继续检查在线决策成本和多次干预后的轨迹分布。

## 7. 统计与证据边界

- 所有区间按源句聚类 bootstrap 4,000 次，保留同句多个状态的相关性；主表使用 95 个有效源句。预设种子 12112004。
- 这些是多个未经多重比较校正的 95% 诊断区间，不是确认性多终点检验，也没有在线推进门槛。
- bootstrap 保留每状态已观察到的八次未来，不重新抽未来噪声；区间不覆盖未采到的未来尾部风险。排序收益的 bootstrap 固定本队列的排名与选择比例。
- GPT-2 已在阶段 11 参与优化目标，本轮仍是同一代理评分器，不能作为独立的人类文本质量评价。
- 单次干预、fixed4 历史和后续策略，不能替代学习控制器反复干预的在线测试。本轮未测延迟或速度提升。
- 第四阶段的论文质量基线复现差距仍未解决，本轮没有给出该差距的原因。
