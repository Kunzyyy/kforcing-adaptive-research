# 注意力决策特征实验：未通过开发推进门槛

2026-09-21

## 结论

本轮真正执行了一个新的模型特征实验：在原19维决策特征上，加入最后一层的6个注意力统计量，检验它们能否帮助选择“保留前两个候选、重算后两个候选”的时机。

**结果：没有通过预先保存的开发推进条件。** 相对原19维模型，新增特征后的选择收益差为 **−0.00694**，97.5%区间为 **[−0.01907, 0.00332]**。这表示没有足够证据支持这组特征带来增益，也不能据此证明所有注意力方法无效。按预设停止规则，不换层、不调参数、不启动新测试来追求正结果。

## 我们的目标、已有成果和缺口

最终目标是做出一个可复现的K-Forcing自适应解码方法：让模型根据当前状态决定提交多少候选、哪里需要重算，并在实际计算成本相当时取得可靠的文本质量收益，或者在质量可接受时缩短生成耗时。

已有成果是实验框架、公开权重复现记录、自适应原型、冻结训练/开发/确认流程、逐状态证据与复核工具。之前的独立确认没有支持现有选择器稳定优于主要对照；论文基线的质量差距仍未解释。本轮增加的是一个有停止规则的特征对照实验。

课题仍处于**方法验证阶段，核心算法优势尚未成立**。缺口依次为：

1. 能够稳定选中有收益重算位置的决策方法，并在全新源句上确认。
2. 在完整生成中计入特征提取、决策、重算和丢弃候选的全部成本，验证质量与耗时取舍。
3. 独立的文本质量证据；用户目前没有评审人选，人工评分仍为0。
4. 解释公开基线与论文的质量差距，或在研究结论中明确限制。作者核对材料已经备好，尚未发送。

因此，不能把现有成果描述为“只差人工评审即可完成论文”。现有代码、实验及负结果可以交给实验室核查，但不是已验证的新自适应算法。

## 为什么尝试注意力

[DAPD原作者项目页](https://ai-isl.github.io/dapd/)研究用注意力作为扩散模型中位置依赖的代理信号。这给了本轮一个具体假设：后两个位置对前两个尚为噪声提示的位置关注越强，把前两个位置替换成真实token后，重算后两个位置可能更有价值。

[K-Forcing论文](https://arxiv.org/html/2606.10820v2)的因果联合push-forward结构与掩码扩散模型不同。本轮不是DAPD复现，注意力也不等同于因果依赖。即使这种信号能预测候选变化，也未必能预测完整续写的质量收益。

## 实验设计

方案、模型代码和输入哈希在提取新特征与拟合前保存，见[固定方案](ATTENTION_FEATURE_PLAN.md)和[冻结清单](results/attention-features/manifest.json)。

| 项目 | 本轮固定设置 |
|---|---|
| 数据 | 原训练/开发表：446状态、253源句，每状态8次既有续写收益 |
| 对照 | 原14维置信度、原19维置信度/位置/EOS、负尾部平均margin规则 |
| 唯一候选 | 原19维加6个注意力特征，共25维 |
| 新增特征 | 后两query对前两噪声位置的注意力质量均值/最大值，以及归一化注意力熵；每项各2维 |
| 提取层 | 最后一个Transformer块，不搜索层或头 |
| 训练 | ridge正则1000，训练折内标准化 |
| 划分 | 按源句分组5折，固定3次重复；同源句不跨训练/验证折 |
| 决策预算 | 每验证折选择floor(N/2)个状态重算；平手按state_id |
| 目标 | 原8次完整续写GPT-2平均NLL收益，不改变目标或重新评分 |
| 推进条件 | 相对19维与简单规则的97.5%双侧区间下界均大于0，且折外MSE低于19维 |

收益定义为keep4的完整续写平均NLL减去split22的平均NLL，越大越好；策略收益按全部状态平均，未选择状态贡献0。这里的数值不是百分比、困惑度变化或人类偏好率。随机对照是每折同样选择数量的解析期望。

原状态文件有447个paired状态，冻结开发表已有446个：另一个状态部分续写过短、评分标签不完整，早在本轮之前已被排除。本轮完整保留既有446状态，不重新选择资格。审计程序最初误把原paired状态总数等同于开发表总数，已修正这个检查假设；冻结的实验方案、提取代码、数据和结果未因此改变。

## 结果

### 主要比较

| 比较 | 选择收益差 | 97.5%源句bootstrap区间 | 下界大于0 |
|---|---:|---:|---|
| 注意力25维 − 原19维 | −0.006942 | [−0.019070, 0.003321] | 否 |
| 注意力25维 − 简单规则 | +0.040306 | [−0.012398, 0.095981] | 否 |

两个区间用于预先固定的两个比较；Bonferroni名义合计95%。开发门槛失败。

### 辅助结果

| 模型 | 折外预测MSE，越低越好 | 相对随机的选择收益 |
|---|---:|---:|
| 原14维 | 0.546754 | +0.057628 |
| 原19维 | 0.535133 | +0.080968 |
| 注意力25维 | 0.534932 | +0.074025 |

25维的MSE仅比19维下降约0.0375%，排序收益反而较低。预测平均误差的小幅下降并未转化为更好的重算选择，不能作为推进理由。原14/19维的折外MSE和相对随机收益点估计均复现既有记录。

这是已经多次用于开发的数据，以上不是独立确认。源句bootstrap固定本轮折外拟合和排序，不能覆盖训练折重叠及反复使用开发数据的全部不确定性。不能用辅助的“优于随机”结果替代主要比较失败。

## 实现与复核

- GPU重放全部446个当前状态，1,784个初始候选与冻结记录一致；原14/19维输入复核通过。
- 前12个状态加只读hook前后logits完全一致；全部446状态重建的注意力加权输出与实际SDPA输出吻合。
- 保存全部注意力概率，另按预先均匀索引保存12组QKV与实际输出；没有生成新的未来分支。
- 单独NumPy float64实现重建RoPE、因果mask、softmax及加权V。12组探针的最大输出绝对误差为3.92×10⁻⁶；全部2,676个新增特征重建通过。
- 使用增广最小二乘，独立于原正规方程求解，重算45次拟合及4,014个折外预测；最大预测误差约2.0×10⁻¹⁵。
- 用源句抽样次数矩阵重新计算14个区间、选择排序和推进门槛，全部一致。

见[数值核查记录](results/attention-features/integrity_audit.json)。这里的“独立”指另一套计算路径，不是另一研究团队的复现或独立人工评审。

## 本轮后的决策

停止这组固定“最后层6特征＋ridge”实现，不将它推进到新测试或在线解码。这个负结果缩小了已验证可行方案的范围，但没有排除其他注意力结构、非线性交互或不同训练方式。

后续方法研究需要一个有机制依据、可在新数据检验的决策信号；在提出它之前，不继续扩大旧开发集上的特征和参数搜索。当前最需要解决的仍是有效选择器和基线可比性。本轮没有新增实际提速、人类文本质量或领先作者工作的证据。
