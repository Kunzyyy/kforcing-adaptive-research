# 第十一阶段：以完整续写评分差预测单次重算收益

2026-09-20，抽样与采集前固定。本轮为离线目标可预测性实验，不直接宣称在线速度、完整自适应策略或人类质量收益。

## 数据与顺序

全新 LM1B 源句 384 个：192 train、64 dev、128 test。排除阶段 1–10 已有六 token 前缀，以及可获得的源行和原句哈希；本轮按这些身份去重。源句至少 12 token，前缀长度 6。抽样种子 11112001。每句四种噪声种子 1103/1109/1117/1123，实际噪声种子 111000000+seed+index*100003；每条轨迹预设考察生成偏移 0 和 8 两处。因此最多 3072 个尝试窗口、6144 条分支文本。

先准备全部身份与 split → 采集/评分 train → 采集/评分 dev → 拟合、选择并锁定预测器 → 才采集/评分 test → 只分析一次。即使 dev 未通过，也按协议对已锁定候选做一次 test，不能重新选择。所有测试标签出现前必须已有锁定文件哈希。

## 两条反事实续写

基础 PFLM fp32、tau=1、无惩罚、最多 122 个新 token。目标状态前沿用 fixed4 轨迹；若在目标偏移前已出现 EOS，记录不可到达，不改选其他位置。目标四候选的前两位含 EOS 时，记录无需决策，不拟合该样本。这两个排除只依赖决策前状态/共同头部，不按哪条分支评分更好筛选。

特征只来自目标四候选的第一次计算，保留既有 confidence14 和 hidden82 定义及阶段 7 的固定投影。随后分成两条分支：keep4 保留四候选；split22 保留前两位，以其为真实历史重算后两位。两条分支在此之后都用 fixed4 继续生成，共享按绝对输出位置索引的噪声，遇到实际 EOS 停止。只干预一次，不更换后续策略。相同 prefix/seed 的两个偏移，其 keep4 完整输出应相同。

这模拟固定 k=4 历史中的一次干预，不能代表学习控制器多次干预后的状态分布。分支成本、长度、EOS 和完整文本均记录；后续轨迹长短可能改变总计算量，离线同数量干预不等于整段生成同 FLOPs 或同延迟。

## 标签

用已校验的本地 GPT-2-Large fp32 对完整可见续写评分，沿用续写单独解码、去特殊 token、不加 BOS、首 token 不计损失的口径。

每对标签 y = keep4 的每序列平均 NLL − split22 的每序列平均 NLL，正数表示重算分支在该评分器上更好。两边均至少两个 GPT-2 token 才有有效标签；其他样本保留并报告为不可评分，不用其拟合或主比较。分支文本相同的零标签必须保留。主统计是每有效分支对等权平均的 NLL 收益，不把它混同于语料 token 加权的 Gen-PPL。

GPT-2 现在参与训练目标，因此虽不参与在线特征，已不再是独立于优化目标的质量验证器。该标签不能称为真实语义质量。教师 NLL 与长度变化仅作旁证；若未来线上成功，还需要其他评分器或人工评价。

## 拟合与比较

六个固定候选：confidence14/hidden82 × ridge alpha=1/10/100。特征均值、标准差和系数只用 train；标准差<1e-8置1。按 dev 中预测分数最高的 floor(N/2) 个样本的平均收益相对同预算随机解析期望排序选模型，平手按名称。保存标准化、系数、dev中位阈值与哈希；不根据 test 改输入、符号、alpha 或阈值。

开发门槛为按源句聚类的探索性 95% 区间下界>0，只作筛选。测试两个主要比较：新预测器相对随机解析期望、新预测器相对阶段 7 冻结预测器；均恰好选择 floor(N/2) 个样本。两项各用 97.5% 双侧区间，Bonferroni family 95%，4000 次源句 bootstrap，seed 11112004。同句所有种子及偏移一起抽样，不把多个分支当独立源句。整批排序固定后重采样，区间条件于观察到的选择与队列，不能等同独立在线阈值评估。

只有 dev 门槛、两个 test 主要门槛都通过才支持推进新方法。若未通过，则报告结果，不追加放宽门槛。简单尾部置信度、已知标签 Oracle、固定 dev 阈值、完整语料 token 加权 PPL、教师 NLL 为探索性比较。Oracle 读取答案，不可部署；整批选一半同样是离线排名，不是在线控制器。

## 验证和边界

旧轨迹验证 keep4 输出与早停 fixed4 一致；单干预 split22 与早停 replay 对齐；特征与已有函数一致，缓存长度正确。严格保存未到达、共同头部 EOS、短文本不可评分等排除记录。独立审计重算数据隔离、标签、train 标准化、ridge 正规方程、dev 选择、冻结 test 预测与 bootstrap。不会在本轮用已看过的 test 开始新的拟合，也不会把离线重算机会排序收益换算为解码加速。
