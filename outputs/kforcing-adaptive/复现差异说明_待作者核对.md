## 可复查的现象

公开 k=4 采样函数，batch=4、tau=1、频率惩罚 0，固定 122 个新位置；质量在首个生成 EOS 截断。两个种子共 256 条输出。GPT-2-Large fp32 对去特殊 token、重新分词的续写评分，不添加 BOS。

| 设置 | 外部 Gen-PPL |
|---|---:|
| AR 公开 CLI 精度路径 | 102.25 |
| k=4 无外层 autocast | 255.14 |
| k=4 外层 bf16 autocast，同噪声 | 259.50 |
| k=4 外层 fp16 autocast，同噪声 | 259.20 |
| k=4 公开推荐惩罚 0.5，第四阶段 | 279.55 |

将前缀一起计分时，AR 为 92.69、fp32 k=4 为 191.73；续写加 EOS 作为 BOS 时分别为 126.47、321.18。以上替代口径仅作敏感性检查。

## 已完成的排查

- 18 组同噪声条件下，自写固定窗口包装与公开采样函数逐 token 一致。
- 第五阶段 256 条 fp32 输出逐 token 重现第四阶段。
- 160 个固定上下文中，fp32 KV 缓存与完整上下文重算的 640 个候选 argmax 全部一致，最大 logit 误差约 9.16e-5。
- 16 个训练/推理末窗口对照中，64 个候选 argmax 全部一致。
- GPT-2 的掩码损失与内置 loss、右侧 padding 不变性检查通过；旧 512 条评分重新计算一致至预设数值容差。
