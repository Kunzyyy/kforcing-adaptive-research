# 第二阶段：运行稳定性与步长收益预测

在采集第二阶段结果前固定本协议。第一阶段文件保留。

## 运行稳定性

对子进程分别测试 PFLM、AR、双模型和交替调用；保存自然退出码，不以强制退出绕过异常。比较 scripted 与 eager 残差辅助函数，并检查教师评分数值差异。Windows 默认使用通过验证的 eager 路径，保留环境变量以复现旧路径。

## 数据与固定方法

- 不训练 PFLM 或教师。使用原有已校验检查点。
- 数据仍为 WikiText-2，属于 LM1B 域外探索。validation 按文章分为训练与开发集，test 用于新测试；排除第一阶段出现过的前缀和源段落。同文章不跨训练/开发集。
- 目标 96 个训练前缀、32 个开发前缀、48 个新测试前缀；每篇文章最多 4 个前缀。若不足则明确失败，不自动缩减结果集。
- 每个前缀为 CLS 加 5 个 wordpiece；最多采集两个状态。先生成固定 4-token 块，未遇到 EOS 才把块的统计量作为下一次决策特征。
- 所有生成和局部分支使用 fp32、频率惩罚为 0。每个状态使用两个独立分支种子；每个种子比较相同上下文、相同逐位置噪声的一次 4 与两次 2。
- 特征仅来自决策前已生成的块：间隔均值/最小值/最后位置、熵均值/最后位置、top1 概率均值/最后位置、块内词汇多样性、上下文长度、间隔和熵的变化、是否存在更早块。计算这些特征的成本尚不作为部署性能。
- 目标为固定 4 相对 2+2 的每 token 教师 NLL 差（正值表示短步在该代理指标上有益）。含 EOS 或前两 token 不匹配的分支记录后排除。主要分析要求同状态的两个分支都有效；不把排除样本悄悄计作成功。

## 模型选择与评价

- 训练标准化特征的岭回归，正则候选仅为 0.1、1、10、100，以开发集 MSE 选择，锁定参数后才输出测试分析。
- 对照包括第一阶段的负平均间隔排名、相反方向的平均间隔排名，以及均匀随机选择的期望收益。
- 报告测试相关性、MSE、固定 50% 选择预算下选中状态的平均收益与随机期望之差，按文章聚类 bootstrap 2,000 次。
- 50% 预算排名是离线可预测性诊断，需要看完整批次分数，不是已实现的在线解码器。oracle 排名仅是使用真实标签的离线上界。
- 如果相对随机的提升区间覆盖零，则不能宣称信号成立。即使局部信号成立，也需独立数据上的在线闭环实验才能宣称解码加速。

## 边界

这是小样本、有 EOS 筛选偏差的局部代理评价，且状态来自固定 4 策略。不能推断人类质量、真实部署收益、学习策略运行后的状态分布或新颖性。不得根据测试结果修改本轮特征、阈值或正则强度再报告同一测试。
