# 决策位置与 EOS 特征：开发诊断与全新确认

2026-09-21。开发诊断、全新源句确认及两份独立审计均已完成。

## 1. 结论

**19维候选未通过本次预设的离线确认。** 新源句上，对随机选择的比较通过；对原14维预测器和简单规则的比较未通过。整体证据尚不足以推进该配置的在线实现，本轮不在这批测试数据上继续换参数。

论文基线差距仍未解决；GPT-2 已是训练代理。本轮没有改变先前阴性结果，没有建立完整课题成功、SOTA或独立人类质量结论。

## 2. 这次只改变什么

原14维特征包括四个位置的 margin（最高与次高分之差）、熵（分数分布的分散程度）、top1分数和头尾差；不显式包含生成位置，也不指明高分 token 是否为 EOS（结束标记）。

新增五个决策当时可获得的量：offset/8、尾部两个位置的 EOS logit 减最大 logit、两个 argmax 是否为 EOS 的标志。共19维；没有用重算之后的 token、实际续写长度或质量评分作为特征。EOS相对分数条件于噪声，不是校准结束概率。

四个开发对照分别为原14维、只加位置15维、只加EOS18维、同时加入19维。全部使用 ridge alpha=1000、相同旧训练/开发数据和原完整续写评分目标，未改用上一轮的等长目标，也未搜索超参数。

## 3. 开发集诊断：有信号，但下界接近零

446状态、253源句；3次5折交叉验证按源句隔离。标准化和拟合仅使用每折训练数据。MSE是预测误差的均方，越低越好。表中为95%描述区间，条件于已拟合折模型，不是全训练过程的不确定性。

| 特征 | 留折预测MSE | 选择收益相对原14维 | 选择收益相对简单规则 |
|---|---:|---|---|
| confidence14 | 0.546754 | +0.0000 [0.0000, 0.0000] | +0.0239 [-0.0210, 0.0695] |
| position15 | 0.545934 | -0.0034 [-0.0200, 0.0146] | +0.0205 [-0.0254, 0.0683] |
| eos18 | 0.536970 | +0.0131 [-0.0082, 0.0355] | +0.0370 [-0.0076, 0.0842] |
| combined19 | 0.535133 | +0.0233 [0.0003, 0.0495] | +0.0472 [0.0025, 0.0953] |

19维的预测MSE比原14维下降约2.13%。这不是文本质量提高的百分比。19维相对原特征的收益区间下界只有0.00033，所以开发证据较弱，不能跳过新数据确认。

原候选共1,784个位置重放一致；原14维重算最大绝对差0.000042。446个开发状态中，尾部至少一个 argmax 为EOS的只有27个，限制了对结束行为的外推。独立增广最小二乘复算全部60次拟合，最大预测差约1.17e-15；原阶段14控制结果复现。

## 4. 全新源句：一次冻结确认

预先固定384个新源句，排除阶段1–16全部已知行号、文本哈希和六token前缀。两模型只在原446个开发状态拟合，随后冻结。每源句考察偏移0/8，每状态8次共享位置噪声的配对未来。只干预一次，之后fixed4，到真实EOS停止。

生成了5,448对分支；681个状态、380个源句进入全部八次可评分的共同集合。0个paired状态因不满足完整可评分条件排除；未替换样本。全部预测与排名在评分前锁定。评分器处理了8,828条唯一文本。

收益是平均 NLL(keep4)−NLL(split22)，正数表示重算后的GPT-2评分较好，不是准确率或人类质量。各方法选相同数量的状态重算，比较的是“选得是否更准”。

三项共同主要比较使用源句聚类 bootstrap 8,000次，各自 **98.3333%** 双侧区间（Bonferroni family95%）；必须三项下界均>0且至少128个有效源句才通过。

| 19维候选的比较对象 | 选择收益差及校正区间 | 单项判定 |
|---|---|---|
| 随机选择 | +0.0442 [0.0140, 0.0746] | 通过 |
| 原14维预测器 | +0.0144 [-0.0084, 0.0385] | 未通过 |
| 简单置信度规则 | +0.0237 [-0.0144, 0.0619] | 未通过 |

最终推进门槛：**未通过**。

## 5. 辅助指标不改变主要判定

- 新测试预测MSE：19维 0.388072；原14维 0.396628；固定训练均值 0.402641。
- 新测试预测相关：19维 0.1982；原14维 0.1238。
- 所有可比状态均重算的平均GPT-2收益：+0.1930 [0.1465, 0.2391]，这里是95%描述区间。
- 所有可比状态均重算的AR教师条件平均NLL收益：+0.2922 [0.2374, 0.3458]。
- 所有可比状态均重算的前向调用数变化（split22−keep4）：+1.0512 [0.8987, 1.1943]。

这些结果仍区分“多算是否平均有用”和“能否提前选准”。调用次数不是实测耗时；队列内选一半也不是可部署在线阈值。启发式分数只用于排序，不用其原始分数MSE与回归模型作优劣比较。

## 6. 核查、限制与下一步

- 开发审计：原数据哈希、特征来源、60次拟合、源句隔离和16项描述区间独立核对。
- 确认审计：完整重建新源句抽样，核对全部噪声哈希、EOS/文本/计数、标签差值、冻结模型与排名；独立复算三项主要区间，精确重放8对新分支。
- 全部评分token计数和算术核对；评分器内置loss检查保留。没有把整个GPT-2评分再运行一遍。
- 只有两个偏移、单一模型/语料和单次干预。384源句为事先固定的本机预算，不保证功效。不能由未通过推断位置/EOS特征在所有规模或模型中无用。
- 公开页面核对见[本轮资料记录](results/decision-features/public-source-check.md)：论文页仍列v2；精确远程commit和权重revision本轮未成功取得，不声称远程版本一定未更新。

当前19维配置到此结束，不继续在这批测试上调参数。优先解决作者检查点/评测配置对应关系；若再改学习目标或扩大训练数据，需单独假设和新的验证数据，不能复用本轮结果作未见确认。
