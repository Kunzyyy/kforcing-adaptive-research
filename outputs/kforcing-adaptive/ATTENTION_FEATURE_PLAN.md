# 决策前注意力特征：固定训练/开发实验

2026-09-21，提取新特征和拟合前保存。本轮只检验一个新假设：**当前后两位置对前两噪声位置的注意力，是否提供置信度、位置和EOS之外的收益信息？**

## 依据和不能直接移植的部分

[DAPD原作者页面](https://ai-isl.github.io/dapd/)将扩散模型的注意力用于位置依赖估计。这提供了考察交互特征的动机。[K-Forcing论文](https://arxiv.org/html/2606.10820v2)使用因果push-forward映射建模联合输出，与独立边缘预测的掩码扩散模型不同。因此这里不把注意力等同于因果依赖，不使用DAPD的无向图或其性能结论，也不声称“注意力用于自适应”本身是新颖贡献。

本地假设来自具体操作：保留前二、重算后二时，前两个位置由噪声提示变成真实token；后两位置对这些位置的关注程度可能影响重算结果。也可能没有预测价值，或仍不能预测完整文本收益，需要实验。

## 唯一新增特征

仅取最后一个Transformer块已有QKV，按实际RoPE、因果mask、head_dim缩放重建后两query的attention概率。对尾部每个位置取：

1. 各头对前两噪声位置的注意力总质量，跨头均值。
2. 上述质量的跨头最大值。
3. 各头完整可见key注意力熵除以log(可见key数)，再跨头平均。

固定六维顺序为mean0/mean1/max0/max1/entropy0/entropy1。候选为原19维+6维=25维；同折训练原19维、14维对照。不试其他层、注意力头、特征、正则、目标或阈值。所有特征只依赖重算前的一次forward，不读取split候选、后续长度或评分作为输入。

## 数据、目标和固定比较

- 使用原train/dev专用白名单：446状态、253源句。旧开发集已多次使用，因此仅是回顾性开发筛选，不能算新独立测试。
- 目标保留原8次完整续写GPT-2平均NLL收益，不改等长目标、不重新评分。
- ridge alpha=1000；标准化和标签均值只由训练折拟合。沿用既有源句分组5折、重复3次的种子14112001/2/3，所有状态同源句同进同出。
- 每个验证折按预测选floor(N/2)个状态，平手按state_id。简单对照固定为负尾部平均margin；随机使用每折实际选择率的解析期望。
- 只设一个候选attention25。开发推进条件：相对原19维、简单规则的收益差各自97.5%双侧源句bootstrap区间下界>0，且候选OOF MSE低于19维。两比较Bonferroni family95%，只是开发筛选；通过也须新源句确认。
- 其他对14维/随机的收益、训练误差、分数相关及注意力特征分布只描述，不用来挽救失败。
- 4000次源句bootstrap，seed=22232001，先在同状态平均三次贡献；固定拟合和每折排名，不覆盖训练折重叠及重复使用开发集的全部不确定性。

## 实现核对和停止规则

全部446状态重放当前四候选，与冻结记录一致；14维置信度和19维额外量复核。前12个状态在无hook和只读hook条件下logits一致。预先均匀选12个状态保存最后层QKV和attention输出输入，用独立NumPy float64路径检查RoPE、mask、softmax、加权V及六特征；其余保存attention概率供特征重建。

单独核查程序重建源句折，用增广最小二乘求解ridge，复核全部45次拟合/预测/排序、收益区间和门槛。原14/19维的OOF点估计须复现既有开发记录。

不改变底层模型或旧结果；不访问旧测试结果做本轮模型选择。通过后仅获得设计全新确认实验的依据；不通过则结束这个固定实现，本轮不换层/调参继续追求正结果。没有人类质量、墙钟提速或基线对齐的新结论；额外QK重建本身有成本，未来必须计入。
