# 第十二阶段：固定决策状态的续写噪声诊断

2026-09-20，数据抽样与采集前固定。本阶段只诊断完整续写 GPT-2 收益标签的重复性，不拟合或筛选模型，不改变阶段 7、11 的锁定参数，也不进入在线性能评价。

## 抽样与控制

96 个全新 LM1B 源句，抽样种子 12112001；排除阶段 1–11 可用的原句行号、原句哈希及六 token 前缀，句长至少 12 token，输入前缀六 token。每句两个状态种子 1201/1213，状态噪声种子 121000000+seed+index*100003；偏移固定为 0/8。最多 384 个尝试状态。偏移前 EOS 和候选前两位 EOS 如实记录，不改选位置。

每个有效状态重复八次：replicate=0..7，future_seed=122000000+index*100003+seed*101+offset*17+replicate*10000019。用 CPU torch.rand 生成长度 122 的 float32 噪声；从状态噪声保留 [0, offset+4)，其余位置取未来噪声同一绝对位置切片。两条分支共用每次的未来噪声，不同重复重新抽样。存储种子、完整混合噪声的 SHA256，以及当前状态、当前四候选噪声、候选和特征；断言八次的这些决策信息完全相同。种子确定性伪随机是重复实验的实现方式。

沿用 fp32 PFLM、tau=1、无惩罚、fixed4 历史，keep4 对照 split22 单次干预，之后两边均 fixed4 到 EOS 或最多 122 个新 token。当前候选完全相同或当前块已结束的状态保留，这些是实际总体的一部分。分支同文本只评分一次，避免数值批次差异伪造零标签的方差。

## 标签和完整性

沿用阶段 11 GPT-2-Large 每完整可见序列平均 NLL：y=NLL(keep4)-NLL(split22)，正值表示重算分支获得较低 NLL。GPT-2 是已经参与优化的代理评分器，不能视为独立的人类质量评价。教师 NLL 只保存旁证。

每状态八次均可评分才进入主要稳定性统计；不足八次的状态保留、报告原因，不填补。源句为 bootstrap 单位，保留同句两个种子、两个偏移的相关性。先验排除不依赖收益正负。既有评分模块不变，新阶段将其非训练数据槽命名为 diagnostic。

预检：原始未来噪声应精确复现阶段 11 分支；改动未来后的分支与独立 early_stop_decoder replay 对齐；所有重复的 history/current noise/candidates/features 相同；噪声头部保持、未来确实改动。采集前锁定协议、采集/分析代码、两个预测器和特征投影哈希。

## 预定分析（均为诊断，不设在线推进门槛）

设每状态收益为 y[i,r]，R=8，m[i] 为八次均值，v[i] 为八次样本方差。主描述量：

1. 组内噪声方差 sigma2=mean(v)；状态均值方差 S2=var(m, ddof=1)；去除 Monte Carlo 方差后的状态间方差 tau2_raw=S2-sigma2/8。保留原始负估计，计算可靠性时才用 tau2=max(0,tau2_raw)。单次/八次均值可靠性分别为 tau2/(tau2+sigma2)、tau2/(tau2+sigma2/8)。这是方差分解估计，不是任何特征预测器可达到的性能保证，也不将有限重复视为真实期望。
2. 前四次均值 A 与后四次均值 B 的 Pearson 相关，及两半严格同号/异号/含零比例；另报八次内同时出现正负收益的状态比例。零标签全部保留，变号不使用人为阈值。

95% 区间采用 4000 次源句聚类 bootstrap，seed 12112004。方差及相关在每次抽样中重算，无法定义的统计量报告 null 与有效重复数。多个诊断区间未经多重比较校正，不作确认性显著性宣称。bootstrap 条件于所观察到的每状态八次续写；不重采样未来噪声，不能覆盖未抽到的未来尾部风险。

预定探索：按初始候选与重算候选是否相同、当前两分支是否均已 EOS 分层；用 A 排序选择恰好一半状态，在 B 上算相对同数量随机解析期望的收益，反向亦然并取平均，估计从独立续写中获得的排序信号。整批排名在 bootstrap 中固定，区间条件于观察到的队列。这个使用未来结果的排名不能在线部署。

阶段 7、11 冻结模型只对决策前特征打分，在八次均值上报告相关、MSE、同数量离线选择收益（95% 描述区间）；不重训、不选优、不修改阈值、不据本轮宣称优于先前测试。无真实延迟、FLOPs 等预算比较。

## 解释与下一步

高组内波动支持检查多次平均标签；两半相关仍低意味着八次尚不能稳定地区分状态，不能直接归因于特征不足。两半相关高而冻结模型表现弱，才支持继续检查特征与训练目标，但仍不是根因证明。无论结果如何，都不将这个诊断变成已证明的自适应质量或加速成果。
