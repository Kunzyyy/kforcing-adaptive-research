# K-Forcing注意力决策特征：本轮复核包

本包只包含一个固定训练/开发假设的证据。先读[实验报告](注意力决策特征实验报告.md)。主要结论：新增最后层6个注意力特征，没有通过预先保存的开发推进条件。

## CPU复核

需要Python和NumPy。在解压目录运行：

```powershell
python verify_attention_features.py
```

程序检查冻结输入哈希，从保存的注意力概率及12组QKV探针重建特征，并独立重算45个ridge拟合、4,014个折外预测和14个区间；打印`passed: true`表示保存证据的计算核对通过，不表示科学假设成立。

默认不写文件。可用`--output 新的核查记录.json`保存本地核查结果。ZIP成员哈希另见`ATTENTION_PACKET_MANIFEST.json`。
