# 19维决策特征：全新源句确认

2026-09-21。开发诊断及独立审计通过后、抽取新源句与采集结果之前固定。

## 冻结候选与对照

唯一候选 combined19：原14维 + offset/8 + 尾部两位置 EOS 相对最大 logit + 两个 argmax EOS 指示。ridge alpha=1000，训练集为原446个 train/dev 状态；仍拟合原完整续写 GPT-2 八次平均 NLL 收益。

同样训练原 confidence14 作为增量对照；负尾部平均 margin 为无训练启发式。没有第二种新增模型，没有超参数搜索。开发结果只支持这次确认，未建立有效算法。

## 样本与执行顺序

冻结协议、代码、两模型 → 排除全部既有数据后抽384个新LM1B源句 → 重放旧开发分支预检 → 新测试采集 → 冻结全体预测/排序 → GPT-2与AR教师评分 → 一次统计 → 独立审计。

- source seed=21192001；按过去相同筛选方式保留至少12个BERT token，输入CLS+5词片。
- 排除阶段1–16已有六token前缀、源句行号、文本哈希。开发诊断和评分审计复用旧源句，没有额外样本。
- 每源句 seed=1901，offset=0/8；state noise seed=211000000+1901+index*100003；future seed=212000000+index*100003+offset*17+replicate*100000007，重复8次。
- 同一个已验证的 keep4/split22 单干预、共享位置噪声、后续fixed4、真实EOS停止、最多122个新token。fp32、tau=1、无惩罚。
- 只读当前 history/noise/logits 提取新增特征。离线为旧采集函数未导出的logits额外重放一次当前状态；这不记为任何在线性能结果。核对四候选和原14维。绝不将 split_candidates、真实续写长度或评分输入预测器。
- 每状态八次全可评分才进入共同集合；不替换不可达/短输出/无效状态，不剔除相同文本。评分前保存全部paired状态预测，之后只按既定可评分规则过滤排序。
- 384源句是本机计算预算下的固定选择，不是保证检验功效的样本量；不看结果后追加样本。

## 三项共同主要比较

在共同状态集合各选 floor(N/2)，平手按state_id。收益 y 是8次 NLL(keep4)−NLL(split22)均值。比较 combined19 对：

1. 同干预概率随机选择，贡献 `(M19-p)*y`；
2. 原 confidence14，贡献 `(M19-M14)*y`；
3. 固定启发式，贡献 `(M19-Mh)*y`。

源句聚类 bootstrap 8000次，seed=21192004；三项各用 **98.3333%** 双侧 percentile 区间（Bonferroni family95%）。只有三项下界全>0且至少128个有效源句，才通过本次离线确认。任何描述性子组、MSE或另一个评分器都不能挽救失败。

报告MSE/相关性、原14维及启发式对随机、AR教师评分、长度/调用量变化作为探索项。统计条件于已拟合模型、固定队列排名和已采样8次未来；重采样保持同源句全部偏移，不把分支当独立样本。

这是离线单干预排序，不是在线阈值、完整自适应策略或相同耗时比较。GPT-2已参与优化，不是独立质量证据。基线复现差距仍未解决；通过也只能推进后续在线和独立质量验证。
