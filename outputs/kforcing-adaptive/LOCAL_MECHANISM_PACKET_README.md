# 局部机制诊断与目标迁移：CPU复核包

先读[实验报告](局部机制与目标迁移实验报告.md)。两个实验分别先冻结、后计算：

1. 机制诊断：真实局部教师收益对完整收益有开发集排序信息，但使用重算后候选和额外教师计算，不能在线直接使用。
2. 目标迁移：固定原19维线性预测器，只更换训练标签，未通过推进条件。

## 运行

解压后，需要Python和NumPy。在目录中运行：

```powershell
python verify_local_mechanism.py
python verify_local_target_transfer.py
```

`passed: true`表示保存证据的数值复核通过；不是算法成功。两个程序默认不写文件；需要保存可以添加`--output 新的核查记录.json`。

`LOCAL_MECHANISM_PACKET_MANIFEST.json`列出ZIP成员哈希。包内含训练/开发状态、评分、完整词表数值探针及必要历史控制。没有旧测试队列、模型权重、Python环境、完整上游依赖或盲评解密key。CPU核查可独立运行；GPU重新评分仍需要原工作区及冻结权重。

这些状态曾多次用于开发，不是独立确认。本包是研究材料，不是人工评审问卷；没有人工结果、在线提速或已验证自适应算法的声明。尚未对外发送。
