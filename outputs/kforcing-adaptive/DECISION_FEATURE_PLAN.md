# 决策位置与结束标记特征：开发集控制诊断

2026-09-21。只研究特征增量，不同时更换评分目标或拟合算法。

## 假设

已有 confidence14 不显式包含生成位置和候选是否接近 EOS。检验补充这些决策当时即可获得的信息，能否帮助预测 keep4 与 split22 的完整续写评分收益。

本轮是已使用过的开发材料上的探索。先前测试失败、评分目标审计和基线差距均保持原结论。不会读取阶段13 test 或阶段15数据进行拟合、排序或调参。

## 固定输入

沿用阶段14由阶段13 train/dev 导出的 446 个状态、253 个源句和原八次平均完整续写 GPT-2 NLL 收益。保持原有效状态、原14维数值不变。仅读取这两个开发 split 的历史状态进行固定输入前向；不生成未来续写、不新评分，不使用 `split_candidates` 或两个分支的实际长度作为特征。

输入、权重和代码在新特征采集前做 SHA 固定。通过同一发布 PFLM 的无缓存前向回放 history_ids、noise、tau=1，核对4个原候选和14维特征，容差 rtol=atol=0.002；不匹配则停止。

## 四组固定特征

1. **confidence14**：原14维，作为控制。
2. **position15**：增加 offset/8（本数据只有0或1）。
3. **eos18**：增加尾部两个位置各自的 EOS logit−最大 logit，以及各自 argmax 是否为 EOS 的两个0/1标志。
4. **combined19**：同时增加位置和四个 EOS 特征。

EOS id=102，所有新增值只取自第一次已计算的四候选前向。相对 logit 是条件于固定噪声的模型分数，不是校准后的结束概率。此处重新前向仅为提取旧日志未保存的信息；未来在线实现可读已有 logits，但额外操作和决策仍需计时，不能声称免费。

## 拟合与对照

- 全部使用同一个 ridge，alpha=1000（未除样本数的平方损失），带不惩罚截距；没有搜索超参数或选择 RBF。
- 沿用阶段14的三次5折源句分组划分：seed=14112001/14112002/14112003。每折标准化、目标均值只来自该折训练源句；验证源句所有偏移一起留出。
- 每个验证折按预测排序选 floor(n/2) 状态，平手按 state_id；固定启发式为负尾部平均 margin，采用相同折内预算。
- 保存全部60次拟合、逐折预测、选择、训练/验证状态ID。报告 OOF MSE、训练MSE、对随机/原特征/启发式的预算内收益差。
- 以源句聚类 bootstrap 4000次，seed=21192026，对每状态三次验证贡献的均值给95%描述区间。此区间条件于已拟合交叉验证模型，未重跑每次 bootstrap 拟合，不代表完整训练过程的不确定性。
- 原特征控制的交叉验证收益和 MSE 应复现阶段14相同配置。另用增广最小二乘独立复算全部60次拟合。

## 预先固定的推进规则

主要关注 combined19 相对原特征的增量；两项单独增加用于解释。只有 combined19 的收益差对原特征、对启发式的95%描述区间下界均>0，且 OOF MSE 点值低于原特征，才记为“值得设计全新确认”。这不是独立成功门槛，也不因某个消融组偶然较好而换候选。

未满足就结束这项补特征假设的当前实现，不在本数据上换 alpha/模型/阈值追求正结果。满足也须用未使用源句验证完整续写、决策成本和独立质量指标，不能直接上线或宣称新方法。

## 交付与边界

独立目录 `results/decision-features`。保留原文件与归档。核查输入哈希、无未来特征、原候选重放、折内数据隔离、标准化、拟合与主要区间。位置只有两种、EOS候选可能较少、小样本、旧开发集选择偏差和论文基线未对齐都限制外推。
