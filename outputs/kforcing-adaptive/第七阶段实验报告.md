# 第七阶段：内部表示带来微弱测试信号，尚未通过在线推进门槛

## 结论与决定

**锁定的小型预测器在新测试集上出现了一个很小的离线信号，但本轮不进入在线解码实验。**

相同 50% 拆步预算下，内部表示预测器相对随机选择的解析期望，AR 教师耦合的 token 一致率提高 **0.464 个百分点，95% 区间 [0.024, 0.879]**。这是值得记录的线索，不是已经成立的算法收益：

- 开发集改善的区间跨零，未通过预设开发门槛。
- 与本次实际随机选择相比，测试差异区间仍跨零。
- 标签是特定噪声耦合下的教师采样一致度，不是文本质量；没有做完整生成、GPT-2 外部评分或速度测试。

因此严格遵守[冻结协议](STAGE7_PROTOCOL.md)：在线推进要求开发和测试门槛同时通过，本轮 **online_experiment_gate_passed=false**。没有根据测试结果重选模型、改阈值或放宽条件。

## 1. 为什么做这一轮

[第六阶段](第六阶段实验报告.md)发现拆步对不同窗口的收益并不相同，但尾部置信度未能优于随机选择。此次测试一个更具体的假设：候选内部表示是否包含置信度之外的收益信息。

基础 PFLM 与 AR 权重保持冻结。训练的只是小型岭回归，即对经过标准化的特征做带正则化的线性加权。

预先固定两类特征：

| 特征组 | 内容 |
|---|---|
| confidence14 | 各位置间隔、熵、top1 概率，以及头尾差异，共 14 维 |
| hidden82 | 上述 14 维，加后两位归一化隐藏向量均值的固定 64 维随机投影，再加 4 个已知噪声值 |

隐藏向量在候选输出线性层之前读取。特征提取完成后才计算第二条分支与 AR 参考，避免把答案或第二次计算的信息放进特征。基础语言模型没有更新权重。

## 2. 数据与执行顺序

从已校验的 LM1B held-out 文件中重新抽取 448 个六 token 前缀，排除此前前缀及阶段 4–6 的源行/原句哈希，并在本轮按前缀和原句哈希去重。

| 数据集 | 唯一前缀 | 每前缀噪声种子 | 局部窗口 |
|---|---:|---:|---:|
| train | 256 | 8 | 2,048 |
| dev | 64 | 8 | 512 |
| test | 128 | 8 | 1,024 |
| 合计 | **448** | — | **3,584** |

执行顺序为：冻结前缀与投影 → 采集 train → 采集 dev → 选择并保存模型 → 采集 test → 仅评价一次。test 采集记录包含已锁定模型的 SHA-256；拟合程序拒绝在 test 标签已经存在时选择模型。

特征标准化和系数仅用 train 拟合。两组特征分别试 alpha=1/10/100，共六个预定候选；按 dev 上一半预算的收益排序选定，相同收益按名称顺序决定。没有用 test 选择候选。

数据无跨 split 的前缀或原句哈希重合，也无既往前缀重合。LM1B shuffled 文件缺少文档身份，因此只能保证这些层级的隔离，不能保证文档或近重复文本级别的独立性。

## 3. 标签究竟代表什么

同一组四个均匀噪声分别驱动：一次固定 4、两次 2+2、AR 逐 token 逆 CDF 参考。标签是 2+2 比固定 4 多匹配的参考 token 数，可正可负。

测试集的 1,024 个窗口中，126 个标签为正、95 个为负、803 个为零。这一任务存在大量零收益窗口；预测器必须区分哪些额外计算真正有益。

逐级蒸馏的公开 k=4 模型不必逐噪声复现原始 AR 映射，因此不能把该标签称为其真实训练准确率、分布距离或语义质量。主汇总使用所有四位置窗口，包括 EOS 后固定位置；测试集中三个分支均无 EOS 的窗口为 969 个，但没有另按该子集重新选模型。

## 4. 开发集选择与锁定

| 候选 | dev 相对随机期望改善，百分点 | 95% 区间 |
|---|---:|---:|
| confidence14，alpha=1 | +0.024 | [−0.586, +0.610] |
| confidence14，alpha=10 | +0.024 | [−0.586, +0.610] |
| confidence14，alpha=100 | +0.024 | [−0.586, +0.610] |
| **hidden82，alpha=1** | **+0.269** | **[−0.293, +0.830]** |
| hidden82，alpha=10 | +0.269 | [−0.293, +0.830] |
| hidden82，alpha=100 | +0.220 | [−0.317, +0.757] |

按预先声明的并列规则，锁定 **hidden82_alpha001**。其开发中位阈值为 **0.0182894412**，开发门槛未通过。协议已规定无论开发是否显著，都只对锁定候选进行一次独立测试，因此随后完成测试；没有因开发结果不理想而换模型。

证据：[六候选开发结果](results/learned-007/dev_candidates.json)、[完整锁定模型](results/learned-007/locked_model.json)。

## 5. 独立测试结果

以下“匹配率”均指特定噪声下与 AR 参考 token 相同的比例。排名选择只是一项离线同预算实验，不代表在线可以预知未来一批窗口的分数。

| 选择方式 | 拆步窗口数 | 教师 token 一致率 |
|---|---:|---:|
| 全部固定 4 | 0 | 32.788% |
| 同预算随机的解析期望 | 512（预算） | 33.325% |
| 固定种子随机选择 | 512 | 33.228% |
| 尾部置信度基线 | 512 | 33.350% |
| **锁定内部表示预测器** | **512** | **33.789%** |
| 知道参考答案的 Oracle | 512 | 36.304% |
| 全部 2+2 | 1,024 | 33.862% |

主要比较采用按前缀聚类、保留八个种子的 2,000 次 bootstrap：

- 预测器 − 同预算随机期望：**+0.464 个百分点 [0.024, 0.879]**。
- 预测器 − 本次随机选择：**+0.562 个百分点 [−0.049, 1.123]**。
- 尾部置信度 − 同预算随机期望：**+0.024 个百分点 [−0.391, 0.439]**。

第一个区间下界仅略高于零；加上开发集未通过、多轮探索以及文档级独立性未知，这还不是稳健的结论。Oracle 使用了答案，展示的是局部可利用空间，不是能够免费实现的策略。

### 固定阈值的预算漂移

直接使用开发阈值时，测试集选择 **575/1,024=56.15%** 的窗口拆步，不再是 50%。其匹配率为 33.911%；相对同样 56.15% 随机概率的期望改善为 **0.520 个百分点 [0.094, 0.935]**。这项结果仅用于暴露阈值转移后的预算变化，不能与 50% 随机结果直接作公平比较。

### 回归误差没有整体变好

预测器测试 MSE 为 **0.29253**，只预测训练标签均值的常数模型为 **0.28136**。说明它没有更准确地预测所有窗口的收益数值。局部排序的小幅改善与整体数值预测不佳可以同时发生；不能把排序结果概括成“学会了可靠预测拆步收益”。

## 6. 正确性核查与可复查材料

- 三个 split 的样本计数、前缀及原句哈希隔离通过。
- 3,584 个窗口中，两个 PFLM 分支的前两个 token 均一致；缓存长度与特征形状检查通过。
- 批量提取的 14 维置信度特征与既有单样本实现核对一致。
- 独立 CPU 审计重算了训练集均值/标准差，验证岭回归正规方程，验证锁定模型哈希，并重算全部测试预测、排序和汇总。
- 所有模型采集、拟合、测试和审计进程正常退出。审计不代表独立复跑所有 GPU 运算，也没有独立重建 bootstrap。

见[审计结果](results/learned-007/integrity_audit.json)、[完整测试结果](results/learned-007/test_analysis.json)、[逐窗口预测](results/learned-007/test_predictions.jsonl)。

## 7. 后续怎么决策

本轮正式结论仍是：**没有达到接入在线解码器的预定门槛。** 此处停止在线推进是遵守实验规则，不是计算或权限受阻。

内部表示留下了一条可以单独验证的线索。如果继续，下一轮应保持本次模型与特征完全不变，事先声明新的确认实验，并使用另一批未见前缀与更长上下文，检查微弱排序收益是否重复出现。不能继续用这 128 个测试前缀调参，也不能将“接近全部 2+2 的匹配率”换算成速度或质量收益。

原有 k=4 外部质量与论文的差距仍未解释；该问题与本轮局部学习诊断分别保留。与作者配置对应关系的核对材料见[复现差异说明](复现差异说明_待作者核对.md)，尚未对外发送。
