# 评分目标审计：收益是否来自文本长度？

2026-09-21。回顾性诊断已完成，独立算术与源句聚类统计复核通过。

## 结论

**本次对照不支持“重算收益只是文本变短”的解释：两条续写比较相同数量的评分位置时，GPT-2 收益仍存在；原 AR 教师评分也同向。** 这使“何时值得重算”仍有研究价值，但目前的两个预测器依然没有通过原来的独立确认，算法尚未成立。

本轮使用第十五阶段已看过的数据，没有重新训练或生成新的测试集。以下均为探索性描述，不能改变第十五阶段的失败结论，也不代表解决了第十六阶段的论文基线差距。

## 做了什么

重新评分全部 **8,810 条唯一续写**，保存每个 GPT-2 评分位置的损失。总分与原记录最大差为 **0.0**。沿用原有效样本：381 源句、682 状态，每状态 8 对未来续写，共 5,456 对；8 对不可评分样本保持排除，1,040 对相同文本保留为零收益。

“等长”指：每对 keep4/split22 的可评分长度取较短者 m，然后分别比较各自前 m 个评分位置。两条文本内容可以不同；不含首个 GPT-2 token、不含 EOS，也不补写被截掉的尾部。该长度依赖两个生成结果，只能在离线诊断时得到。

损失差定义为 NLL(keep4)−NLL(split22)，正数表示重算后得分较好。NLL 是平均每个评分 token 的负对数概率，单位为 nat/token；**0.255 不是提高 25.5% 的准确率或文本质量。**

## 1. 收益在等长比较后仍存在

先平均每状态的八次重复，再平均状态。区间为源句聚类 bootstrap 4,000 次所得的 95% 描述区间，不把每条分支当独立样本。

| 比较口径 | 平均 NLL 收益 | 95% 描述区间 |
|---|---:|---|
| 原完整续写 GPT-2 | +0.2249 | [0.1662, 0.2863] |
| 等长 GPT-2 | +0.2546 | [0.1917, 0.3243] |
| 原收益减等长收益 | −0.0297 | [−0.0683, 0.0074] |
| 原 AR 教师条件评分 | +0.2750 | [0.2182, 0.3315] |

“原收益减等长收益”只是更换评分区间后的代数剩余项，不能称为长度的因果贡献。AR 教师包含前缀条件和生成 EOS，使用 BERT token；其数值尺度与 GPT-2 不直接比较。它是另一模型诊断，也不是人类质量验证。

按全部评分 token 加权的完整续写 GPT-2 PPL 为 **215.31 → 189.70**，对应 NLL 差 0.1266 [0.0689, 0.1875]。这与上表的逐序列平均 NLL 是不同统计量。这些分支只做一次干预，并重复使用同一源句的状态和未来，不是一个完整在线自适应算法的测试结果。

## 2. 长度没有整体变短，计算量增加

此表定义为 split22−keep4；正数表示重算后更长或计算更多。

| 指标 | 平均变化 | 95% 描述区间 |
|---|---:|---|
| BERT 新 token（含生成 EOS） | +0.183 | [−0.369, 0.723] |
| GPT-2 评分 token | +0.522 | [0.005, 1.057] |
| 模型前向调用次数 | +1.040 | [0.903, 1.175] |
| 计算候选 token 数 | +2.165 | [1.618, 2.703] |

因此存在的是“投入更多计算后，代理评分平均改善”的信号，尚不是节省计算的结果。调用数也不能直接换算为实测耗时。

生成结果分组进一步显示，缩短并不自动获得更高原评分：

| 重算后的 GPT-2 评分长度 | 对数 | 原平均收益 | 等长平均收益 |
|---|---:|---:|---:|
| 更短 | 1,842 | −0.1062 | +0.2504 |
| 相同 | 1,510 | +0.0678 | +0.0678 |
| 更长 | 2,104 | +0.6275 | +0.3924 |

分组由生成结果决定，只能用于描述，不能据此建议在线“强制变长”。

## 3. 标签更稳定不等于模型会预测

| 状态级相关性 | 数值 |
|---|---:|
| 原收益与等长收益 | 0.837 |
| 原 GPT-2 收益与 AR 教师收益 | 0.571 |
| 等长 GPT-2 收益与 AR 教师收益 | 0.569 |
| 原收益的前四次/后四次相关 | 0.731 |
| 等长收益的前四次/后四次相关 | 0.843 |
| 原收益与长度变化相关 | 0.301 |
| 等长收益与长度变化相关 | −0.012 |

等长口径在这批数据上与长度变化的线性相关较弱，两半平均收益相关较高。这是改进训练标签的候选线索，不是新指标已经更能代表人类质量的证明；0.843 也不是预测器准确率。

原冻结半预算选择在等长口径下：

| 原预测器 | 对随机选择的收益差 | 对简单置信度规则的收益差 |
|---|---|---|
| 线性 | +0.0266 [−0.0067, 0.0638] | +0.0025 [−0.0497, 0.0655] |
| RBF | +0.0453 [0.0112, 0.0835] | +0.0213 [−0.0301, 0.0859] |

这里使用未作多重比较校正的 95% **描述**区间。RBF 对随机的正区间不能作为通过依据：这是看过测试结果后的新指标，而且对简单规则的区间仍跨零。原第十五阶段四项主要比较使用 98.75% 校正区间，两个候选均失败，结论保持不变。

## 4. 对后续工作的影响

1. **保留自适应重算这个问题。** 当前证据没有把重算信号解释成单纯的输出缩短；目标两半相关也说明它含有可重复成分。
2. **暂不把现有预测器部署为新方法。** 关键缺口仍是：在看到重算结果之前，能否以足够低的成本决定何时多算。离线把结果读出来后的排序不满足这一要求。
3. **基线对应关系仍应优先核对。** 本轮没有改动权重或归一化；作者检查点、完整评测配置和原环境固定输入对照仍是最有价值的外部证据。
4. **若研究新标签，先回到训练/开发集。** 需要检验“相同评分长度是否改善预测与完整续写表现”，并且在新测试上同时保留原完整续写指标、独立质量评价和真实 EOS 停止后的耗时。不能再次把阶段15包装成未见确认集。
