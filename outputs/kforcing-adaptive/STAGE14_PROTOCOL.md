# 第十四阶段：特征可预测性与过拟合诊断

2026-09-20，新增诊断计算前固定。只分析阶段 13 已有 train/dev，不采集新测试、不对既有 test 再评价。这是观察过历史失败结果后设计的回顾性探索，不能称为独立确认。

## 数据与目标

分析程序只允许读取 averaged-013 的 train/dev states、labels、scoring、collection，以及身份 prefixes 和历史 manifest/audit 元数据。不得读取 test 的特征/分支/标签/预测，亦不使用混有 test 的 state_targets。准备阶段导出 train/dev 专用数据及输入路径/哈希清单，之后所有拟合只读该副本。

保留阶段 13 既有完整八次评分状态，预计 train336+dev110=446；不恢复此前缺少评分的状态。每状态以八次 GPT-2 NLL 收益均值为目标，全部零收益保留。原 source split 仅用于记录和置换分层。该数据早已被用于训练或选择，本轮无新 held-out 声明。

## 特征与预定 18 配置

固定原有82维特征，不引入事后分支文本或评分等在线不可用信息。特征组：confidence14=[0,14)，hidden64=[14,78)，noise4=[78,82)，hidden82=[0,82)。noise4 是特征消融，当前噪声会影响候选，不称为无信号负对照。

- confidence14 与 hidden82：各 ridge alpha=1/10/100/1000/10000，10 配置。
- hidden64 与 noise4：各 ridge alpha=1/1000，4 配置。
- confidence14 与 hidden82：各 RBF kernel ridge lambda=1/10，4 配置。gamma=1/维数；用训练折均值/标准差标准化，核矩阵按训练折中心化，中心化目标拟合后加训练均值。带宽不另行调参。

每次拟合的均值、标准差、目标均值、核中心化均仅用当前训练折。正则参数按通常未除样本数的平方和损失定义；学习曲线中参数数值固定。非线性探针仅覆盖这一固定核和参数范围，失败不证明所有模型或特征都无信息。

## 按源句重复的嵌套交叉验证

外层 5 折 × 3 次重复，种子 14112001/14112002/14112003。按 prompt_id 分组，源句排序后以 NumPy default_rng 打乱，再按位置 mod 5 分折；同句全部状态同进同出。不同重复不当作独立数据。

每个外层训练池再做 4 折分组内层验证，种子 14113000+repeat_index*100+outer_fold。按内层验证累计的全状态等权半预算收益选择18配置之一；分数最大者入选，平手按配置名。选定后在整个外层训练池重拟合，再评价外层。所有18个固定配置另存外层结果，用来观察稳定性，不能将事后最优值当无偏泛化估计。

每个验证折分别选该折预测最高的 floor(N/2) 状态；收益=mean((selected-p_fold)*y)，p_fold=floor(N/2)/N。不能跨不同拟合模型的验证折统一排名。整体按状态加权、再对三次重复等权平均。重复不足整除导致的预算差异由 p_fold 精确处理。

保存折内训练/外层验证 MSE、训练均值常数基线、有效自由度 trace(H)、全体逐状态外层预测/选择、嵌套选择频次。MSE skill=1-外层模型 SSE/同折训练均值基线 SSE。训练误差低、外层误差高是过拟合迹象，不等于已证明唯一失败原因。相关仅作描述，不把重复预测数当独立样本量。

外层排序收益的描述性95%区间按源句 bootstrap4000次，seed14114004；每状态先平均三次收益，再随源句重抽。固定已拟合预测，不重新训练，因此区间条件于当前拟合与折划分，不能处理所有交叉验证模型之间的训练重叠。多个诊断区间不作确认性宣称。

## 标签打乱对照

199次条件置换，seed14115001。将每个源句的所有八次收益向量作为整体，按偏移对齐移动到另一个源句；只在相同原 train/dev split、相同有效偏移集合的源句间交换。这样保持同句相关、偏移组成与原划分的目标分布。单元素层保留不动，报告层大小。

每次置换完整重算训练目标均值、回归、内层配置选择和外层收益。可利用固定特征下的线性预测算子批量计算全部置换，但不得复用真实标签选出的配置。每次也计算18固定配置的最大收益，作为搜索多个配置的置换参照。

嵌套流程诊断 p=(1+置换嵌套收益>=真实嵌套收益的次数)/200。固定候选报告以每次18配置最大收益为参照的 family-max 校正 p。它们是这份历史开发数据、既定折和条件交换假设下的探索性检验，不将其包装为全研究多阶段校正或独立测试通过。

## 学习曲线

预定四个 ridge 配置：confidence14/hidden82 × alpha1/1000。每个外层训练池先按源句用 seed14116000+repeat_index*100+fold 排定次序，取前25%/50%/100%（floor，至少1句），子集嵌套；同一子集供四配置共用。评价始终使用同一外层验证折，保存训练句数、状态数、训练/验证 MSE、常数基线和排序收益。100%点应与相同固定配置外层结果一致。该曲线不外推尚未采集的更多数据收益。

## 审计与解释

冻结本协议、实现和 train/dev 输入哈希后运行。独立审计核对输入白名单、数据派生、源句/内外层隔离、全体置换的层内双射、折内标准化、直接回归预测、全部真实标签内外层选择、主要 bootstrap 与置换 p。固定前三个置换实例另用直接拟合交叉核对其配置结果与嵌套选择；其余实例检查置换结构和已保存统计，不虚称全部独立重拟合。

若连嵌套结果也弱，则优先考虑特征/模型/样本规模的限制；不能仅凭本轮断言特征绝对没有信息。若有信号，也必须再锁定方法并用全新源句确认。GPT-2 是已优化的代理评分器；本轮不测在线速度，不重开历史 test，不推翻阶段13阴性结果。
